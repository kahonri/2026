# COSS ブログ記事制作

COSS THE GEL（コスザゲル / オールインワンスキンケアゲル）を販売する
Shopifyブログ `coss-coss.jp` の記事を制作するスキル。

「運動×美容」の両立をテーマに、運動する30〜50代女性へ商品を自然に届けるSEO記事を作る。

---

## 実行モード

ユーザーの依頼に応じて以下を判断する。指定がなければ 1→2→3 を通しで実行する。

| モード | トリガー例 | 動作 |
|--------|-----------|------|
| **1. 執筆** | 「〇〇の記事を書いて」「キーワード△△で」 | Markdown原稿を生成 |
| **2. HTML変換** | 「Shopify用に変換」「HTMLにして」 | Markdown → Shopify HTML＋画像指示書 |
| **3. チェック** | 「チェックして」「AI臭くない？」 | 品質チェック（スクリプト＋目視） |
| **4. リライト** | 「この記事を直して」 | 既存記事にチェック結果を反映 |

### 編集範囲を守る（2026-10 追加）

リライト・校正では、**指定された編集範囲の外を変えない。** たとえば「ページ下部のCTAは変更しない」
と指示があれば、CTAが現行テンプレートと違っていてもそのまま残す。
範囲外で気づいたこと・確認したいことは、本文の編集とは別にまとめて共有する。

## STEP 2: 出典を集める ★書く前に必ずやる

**記憶で書かない。** ここを飛ばすと、もっともらしい数値を作ってしまう。
旧記事の「筋肉1kgが1日13kcal」「体重55kgで300〜400kcal」「3〜4週間後が目安」は
すべてこの工程がなかったために生まれた架空の数字だった。

必ず `references/evidence-rules.md` を読んでから始める。

1. 記事で書く主要な主張を先に洗い出す
2. WebSearch / WebFetch で、主張ごとに一次情報を探す（**3〜5本**）
3. 検索結果の要約で済ませず、**元ページや論文アブストラクトを開いて中身を確認する**
4. 「主張 → 出典 → 発行年 → 本文で明示するか」の対応表を作る
5. **裏が取れなかった主張は書かない。** 粒度を落とすか、その話題ごと外す

使ってよい出典の階層、資料の新しさ（原則5年以内）、本文での書き方、
「本文中の出典は1機関につき1回まで」のルールは `references/evidence-rules.md` にある。

## STEP 3: 執筆する

必ず `references/writing-rules.md` を読んでから書く。構成要件・カテゴリ別の書き分け・
文体ルールが入っている。

同時に以下3つのルールを守る。**構成より優先する。**

- `references/evidence-rules.md` — 出典・数値・参考資料・免責のルール。**最優先。**
- `references/yakkihou.md` — 薬機法・景表法の表現ルール。効果効能の断定を避ける。
  化粧品を扱う記事なので、ここを外すと法的リスクになる。断定を外す語尾の変換表もここ。
- `references/ai-humanize.md` — NG表現リスト。COSSブログのリライト作業から抽出した実地ルール。

**ルールが衝突したら evidence-rules.md ＞ yakkihou.md ＞ ai-humanize.md ＞ writing-rules.md の順。**

書き上げたら `coss/blog/` に `{NN}-{slug}.md` として保存する。
`{NN}` はキーワード管理表A列のNo（2桁ゼロ埋め）。表と記事を突き合わせるための合番なので必ず付ける。

### 特に外せない10点

1. **導入部に「この記事で分かること」リストを書かない。** すぐ本題に入る。
2. **「運動後のケア」セクションは必須。** 場面描写→課題→商品紹介の順で書く。
   「そんなときに便利なのが〜」での導入は禁止。
3. **まとめを箇条書きにしない。** 2〜3文の文章＋具体的なアクションアドバイスで締める。
4. **H2見出しの最低1つにキーワードを入れる（必須）。** ただし見出しを不自然にしてまで
   入れない。「効果を最大化するコツ」→「ランニングの効果を最大化するコツ」のように、
   主語を補う形にすると自然に収まる。
5. **効果を断定しない。** 「改善する」「解消する」「くすみが取れる」「毛穴が開く」は使わない。
   血行や代謝の変化と美容効果を因果で直結させない。詳細は `references/yakkihou.md`。
6. **タイトルに数字があるとき、他の見出しに別の数字を出さない。**
   「7つのこと」の記事に「3つの変化」があると読者が混乱する。
7. **出典のない具体的な数値を書かない。** 「週3回が最適」「3〜4週間で変化」「8,000〜15,000円台」
   はすべて禁止。数値を出すなら出典とセットにする。
8. **本文に機関名・誌名を書かない。** 一般表現＋注番号（※1）にして、
   記事末の参考資料で担保する。本文の注番号と参考資料は1対1で対応させる。
9. **参考資料セクションを必ず入れる。** まとめの後、記事末尾CTAの前。URLは載せない。
   免責注記は記事のジャンルで選ぶ（スキンケア用／運動用・目安あり／運動用・目安なし。運動×美容は両方）。
10. **俗説の打ち消しを1〜2箇所入れる。** 読者が信じていそうな通説に線を引き直す。
   例：「大量に汗をかく＝脂肪がたくさん燃えている、というわけでもありません」

## やってはいけないこと

- 効果効能の断定（「改善する」「治る」「解消する」「シミが薄くなる」）
- 身体機能の変化と美容効果を因果で直結させる（「血行が良くなるので肌がきれいになる」）
- 医学的根拠のない断定・根拠のない「〜の原因になります」
- 「老廃物」「デトックス」「毛穴が開く」など誤解を招く美容表現
- 極端なダイエット法の推奨
- 他社商品の批判・比較
- 「絶対」「必ず」の多用
- 「簡単に痩せる」「すぐに効果が出る」「これだけでOK」
- **出典のない具体的な数値**（週◯回／◯分／◯週間で／◯円台／キロ◯分／◯kcal）
- 効果のメカニズムを解説するブロック（旧08の「EPOC効果」のような節）
- 病名・診断名を出すこと、「何日休めば治る」など治癒の見通しを示すこと
- 不安を煽ってから商品につなぐこと
- 観察研究の結果を「〜すると〜になる」と言い換えること
- 裏づけのない「よく聞く」「〜する人が多い」「〜のほうが確実」
- 商品を「誰でも同じ効果」「1本で十分」と読ませること
- 馴れ馴れしい口語（「でも大丈夫。」「わかります。」「正直しんどい。」）

詳細と言い換え例は `references/yakkihou.md` にある。
