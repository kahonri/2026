# COSSブログ 薬機法・景表法チェック

化粧品（COSS THE GEL）を扱うブログなので、記事は**化粧品等適正広告ガイドライン**の
範囲に収める。医薬品的な効能効果をうたうと薬機法66条（誇大広告）、
根拠なく効果を断定すると景品表示法（優良誤認）に触れる。

**このファイルは `ai-humanize.md` と同じく執筆時に必ず参照する。**
AI文体の修正よりこちらが優先。表現を弱めた結果で文章が読みにくくなるのは避けるが、
断定を残すよりは弱める。

---

## 基本の考え方

化粧品で言えるのは「肌の状態を保つ・整える」まで。「変える・治す」は言えない。
運動・生活習慣についても、身体機能の変化と美容効果を因果で直結させない。

| | 言える | 言えない |
|---|---|---|
| 化粧品 | 肌を整える／すこやかに保つ／うるおいを与える／ツヤを与える／肌を清潔に保つ／乾燥を防ぐ | 改善する／治る／シミが薄くなる／毛穴が小さくなる／肌質が変わる |
| 運動 | 〜と感じることがあります／〜な印象につながることがあります／〜見えることがあります | 〜が改善します／〜が解消します／血行が良くなるので肌がきれいになります |

**削除ではなく言い換える。** 情報量と説得力は残す。過度に曖昧にすると記事の価値が落ちる。

言い換えで「〜と感じる人が多いです」と書くと、今度は頻度の主張になる。裏づけがなければ
「〜と感じる人もいます」「〜こともあります」にする（`evidence-rules.md` 原則6）。

## 言い換え表

### 状態変化の断定

| NG | 言い換え |
|----|---------|
| 猫背が改善される | 姿勢が変わってきたと感じる人もいます |
| 腰痛が改善する | 腰まわりが楽になったと感じる人もいます |
| 肌荒れが治る／改善する | 肌の調子が落ち着いてくることがあります |
| 便秘が解消する | お通じのリズムが整いやすくなります |
| くすみが取れる／消える | 顔色が明るく見えることがあります |
| シミが薄くなる | ※化粧品では言えない。予防（紫外線対策）の話に振る |
| 毛穴が小さくなる／目立たなくなる | 毛穴が気になりにくい状態を保ちやすくなります |
| たるみが改善する | ハリのある印象を保ちやすくなります |
| ニキビが治る／消える | 肌荒れが起きにくい状態を保ちやすくなります |
| 疲れが取れる | 疲れが残りにくいと感じる人もいます |
| 肌質が変わる | 肌の調子の傾向が変わってきたと感じることがあります |

### 因果の直結

| NG | 言い換え |
|----|---------|
| 血行が良くなることで肌がきれいになる | 運動を続けている人の中には、肌の調子が安定していると感じる人もいます |
| 血流が増えて肌に栄養が届く | ※医学的断定。使わない。「体を動かしたあとは顔色が明るく見える」程度に |
| ターンオーバーが整う／正常化する | 肌の生まれ変わりのリズムは生活習慣の影響を受けます（断定しない） |
| 老廃物が流れる／デトックス | ※使わない。汗をかいた後の話は「汗と皮脂を洗い流す」に置き換える |
| 毒素が排出される | 使わない |
| 代謝が上がって痩せる | 消費エネルギーが増えやすくなります |

### 原因の断定

「〜の原因になります」は根拠が明確なとき以外は使わない。

| NG | 言い換え |
|----|---------|
| 汗を放置すると毛穴詰まりの原因になります | 汗や皮脂が肌に残ったままだと、毛穴の汚れにつながることがあります |
| 睡眠不足は肌荒れの原因です | 睡眠不足が続くと、肌の調子が乱れやすくなることがあります |

### 化粧品まわりの用語

| NG | 言い換え |
|----|---------|
| 浸透する（角層より深い印象） | 角層までうるおいを与える／なじむ |
| 有効成分／効く | 配合成分／使いやすい |
| 殺菌・除菌・抗菌 | 肌を清潔に保つ |
| 肌が再生する／若返る | 使わない |
| 医薬品・治療を連想させる語（治療／処方／効能） | 使わない |

※「浸透」は「角層まで」と範囲を明記すれば化粧品表現として使える。単独では使わない。

### 生理現象の俗説

| NG | 言い換え |
|----|---------|
| 運動で体温が上がると毛穴が開く | 汗をかいたあとの肌は、皮脂や汗が肌の上に残った状態です |
| 毛穴を開いて汚れを出す | 汗と皮脂を洗い流す |

「毛穴が開く／閉じる」は科学的に不正確で美容記事の典型的な誤り。使わない。

## 断定を外す（薬機法とは別枠）

薬機法にかかる効果効能とは別に、**一般論の断定**も外す。
リライト版が「人間らしい」と評価された実体は、口語でくだけたことではなく、
**押し付けをやめたこと**にある。

| NG | 言い換え |
|----|---------|
| 〜した方がいいです | 〜しておくと安心です／〜という方法もあります |
| 〜が正解です | 〜がひとつの目安です |
| 〜が最適です／〜が理想です | 自分に合う方法を見つけましょう |
| 〜が効率的です | 〜という考え方もあります |
| 〜を防げます／〜を防ぐ | 〜の負担を減らせます／無理なく続けられます |
| 〜になります（断定的な因果） | 〜こともあります |
| 逆効果です | 〜につながることがあります |
| 必ず／絶対／全て | 使わない |
| 妥協しない／ケチらない／省かない | 使わない（煽り） |

### 語尾を回して単調さを避ける

丁寧語のまま断定を外すと単調になりやすい。語尾を散らす。

> 〜しましょう／〜という方法もあります／〜とよいでしょう／〜こともあります／
> 〜がひとつの目安です／〜と感じる人もいます／〜と報告されています

### 通説の打ち消しには「〜わけではありません」を使ってよい

`ai-humanize.md` は「〜ではありません。〜です」（否定→肯定）をAI構文として禁止しているが、
**俗説を打ち消す場面は例外**。むしろ企業ブログの信頼はここで作る。

> 心拍数の高さがそのまま消費カロリーの多さを表す**わけではありません**。
> 筋肉量が増えたからといって基礎代謝が急激に高くなる**わけではありません**。
> 〜と**一概には言えません**。

禁止されているのは「AだけではありませんBです」という飾りのコントラスト構文であって、
事実として否定する文ではない。

## 不安を煽って商品につながない

旧版は、肌トラブルの不安を作ってから商品を出していた。この導線は使わない。

| NG（旧版） | 言い換え（リライト版） |
|----|---------|
| そのまま放置すると毛穴の汚れになり、肌荒れにつながる | 汗をかいた状態が長く続くと、肌のべたつきや刺激が気になることもあります |
| 想像以上の速さで乾燥が進みます | シャワーや洗顔のあとは乾燥を感じることがあります |
| 肌荒れで足が遠のくのを防げます | （書かない） |

## 肌トラブルがケアだけで片づくように書かない（2026-10 追加）

「条件を整えれば済む」「このケアをすれば大丈夫」と受け取れる書き方をしない。
肌荒れや赤み、かゆみなどを扱うときは、症状が続く場合の相談先（皮膚科などの医療機関）を示す。

| NG | 言い換え |
|----|---------|
| 洗い方と保湿を整えれば済みます | 洗い方と保湿を見直すと、肌の調子が落ち着いてくることもあります。赤みやかゆみが続く場合は皮膚科に相談してください |

---

## 商品を「誰でも・これだけで」と受け取らせない（2026-10 追加）

商品は、手間や持ち物を減らしたい場面に合う**選択肢のひとつ**として紹介する。

- 誰でも同じ効果が得られる、と受け取れる表現を使わない
- 「1本で十分」「これだけでいい」と、必ず1本で足りると受け取れる表現を使わない。
  乾燥が気になる人が重ねて使うことを否定しない

---

## 論文の強い言い回しを見出しに持ち込まない（2026-10 追加）

「諸刃の剣」「両刃の剣」のような論文や総説の比喩は、一般の読者には何の話か伝わらない。
見出しにも本文にもそのまま使わず、何がどう起こりうるかを具体的に書く。

| NG | 言い換え |
|----|---------|
| 運動は肌にとって諸刃の剣 | 運動中の汗や紫外線が、肌の負担になることもあります |

---

## 病名・診断名を出さない

痛みや不調は「受診すべきサインの列挙 → 医療機関へ」の型で書く。
病名を挙げない。「何日休めば治る」など治癒の見通しを示さない。
詳細と実例は `references/evidence-rules.md` を参照。

---

## 数字見出しのルール

**記事タイトルに数字が入っている場合、その数字に対応する見出し以外では数字を使わない。**

「ジム初心者が知るべき7つのこと」という記事の中に「運動がもたらす3つの変化」があると、
読者は7つなのか3つなのか分からなくなる。

- タイトルの数字に対応するセクションは、番号付きで列挙してよい（1.〜7.）
- それ以外の見出しは「運動で変わること」のように数字を外す
- タイトルに数字がない記事は、見出しに数字を使ってもよい（ただし1記事1系統まで）

## やってはいけないこと（従来からの継続）

- 医学的根拠のない断定
- 極端なダイエット法の推奨
- 他社商品の批判・比較
- 「絶対」「必ず」の多用
- 「簡単に痩せる」「すぐに効果が出る」「これだけでOK」

## 投稿前チェック

`scripts/check_article.py` が上記のNG語を機械判定する。
そのうえで以下を目視で確認する。

- [ ] 肌や体の状態が「変わる」と断定している箇所がないか
- [ ] 身体機能（血行・代謝）と美容効果を「だから」でつないでいないか
- [ ] 「〜の原因になります」が根拠なしで使われていないか
- [ ] 化粧品の説明が「整える・保つ・うるおいを与える」の範囲に収まっているか
- [ ] タイトルの数字と本文の数字が食い違っていないか
- [ ] 「〜した方がいいです」「〜が正解です」「〜が最適です」が残っていないか
- [ ] 見出しが効果や予防を約束していないか
- [ ] 不安を煽ってから商品につないでいないか
- [ ] 病名・診断名を書いていないか
- [ ] 肌トラブルがケアだけで解決するように書いていないか（相談先を示したか）
- [ ] 商品が「誰でも同じ効果」「1本で十分」と受け取れる書き方になっていないか
- [ ] 「諸刃の剣」など論文の比喩が見出し・本文に残っていないか
