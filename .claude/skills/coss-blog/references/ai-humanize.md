# COSSブログ AIヒューマナイザー

2026年3月に公開した「ヨガの効果はいつから？」記事のリライト作業から抽出した実地ルール。
ベースは Humanizer スキル（Wikipedia "Signs of AI Writing" 準拠）の日本語記事への適用。

もとは `coss/blog/ai_humanize_rules.md` にあったものをこのファイルに一本化した
（2026-08-19）。旧ファイルの内容は git 履歴に残っている。

**このファイルのルールが最優先。** 構成が正しくてもここを外すと差し戻しになる。

## NG表現リスト

### 文体・語尾

| NG | 代替 |
|----|------|
| 「安心してください」 | 使わない。直接本題に入る |
| 「〜ですよね？」の多用 | 1記事に1〜2回まで |
| 「さあ、〜しましょう」「さあ、〜へ！」 | 使わない。具体的なアクションか素直な締めに |
| 「一緒に〜しましょう」「見ていきましょう」「解説していきます」 | 使わない。そのまま始める |
| 「〜はずです」（根拠のない断言） | 「〜ことが多い」「〜傾向があります」 |
| 「〜からこそ」の多用 | 1記事に1回まで |
| 「内側と外側の両方から」 | 具体的に何と何を組み合わせるか書く |
| 「多角的に働きかけてくれます」「多面的に」 | 何がどう変わるかを具体的に |
| 「〜ではありません。〜です」（否定→肯定） | AIの定番コントラスト構文。使わない。**ただし俗説の打ち消しは例外**（`yakkihou.md` 参照） |

### 記号・構造

| NG | 代替 |
|----|------|
| 「——」（ダッシュ）の多用 | 読点「、」か句点「。」で文を切る |
| 商品紹介の箇条書き「特徴:」セクション | 本文の流れの中に溶け込ませる |
| まとめを箇条書きにする | 1〜2文の実用的なアドバイスで終わる |
| キーワード＋コロンの見出し（「ヨガ 効果のポイント:」） | 使わない |

### CTA（商品紹介）への導入

| NG | 代替 |
|----|------|
| 「そんなときに便利なのが〜」 | ユーザーの具体的な場面を先に描写してからつなぐ |
| 「私たちCOSSでは〜を提供しています」 | 「〜ために開発したのが〜です」など目的から入る |
| 製品特徴の箇条書き | 1〜2文で「何ができるか」「いくらか」だけ書く |

### 禁止する締めのパターン

- 「〜あなたの毎日がもっと輝くはずです」
- 「まず一歩を踏み出してみましょう」
- 「新しい自分に出会えるはずです」
- 「今日から始めてみてください」（単体で使う場合）

**代わりに使うもの:** 次の一歩になるアクション
- 「まずは近くのジムを見学したり、体験利用があるか確認したりするところから」
- 「〜が気になるなら、まず○○を見直してみてください」
- 「体調を確認しながら、自分が続けやすい形を探してみましょう」

※旧版は例として「週2〜3回から始めると続きやすいです」を挙げていたが、
出典のない数値なので差し替えた。頻度を書くなら出典とセットで（`evidence-rules.md`）。

## やること

### 構造のバラツキを出す

AI文章は各段落・各セクションが均等な長さになりやすい。意図的にバラつかせる。

- 短い段落（1〜2文）と長い段落（4〜5文）を混ぜる
- 全セクションを同じ形式にしない
- 完璧なタイムライン（1週間/1ヶ月/3ヶ月/半年/1年）を使うときは、各段階の説明量を変える

### 具体性を上げる（ただし出典とセットで）

> **2026年9月改訂。** 旧版の例は「ウエスト周りが引き締まってくる」「周囲から『痩せた？』と
> 聞かれるのはこの頃」「ファンデーションのノリが変わる」だった。どれも効果の断定で、
> 旧05・旧08の問題箇所そのもの。具体性の出し方を差し替えた。

具体性は**捨てない**。捨てると記事の価値も落ちる。出し方を変える。

| 曖昧 | 悪い具体化（断定） | よい具体化（出典つき） |
|------|------|------|
| 効果が期待できます | ウエスト周りが引き締まってくる | 8週間程度続けた場合に柔軟性の指標が16〜33%向上したという報告もあります |
| 無理のない頻度で | 週3回・1日おきが初心者には最適です | 厚生労働省の「健康づくりのための身体活動・運動ガイド2023」では、成人に対して筋力トレーニングを週2〜3日行うことが推奨されています |
| 正しく選びましょう | ぴったりサイズより少し大きめが正解です | つま先は、最も長い指からシューズの先端まで1〜1.5cm程度の余裕がひとつの目安です |

### 数値は段落にひとつまで ★重要

出典が取れた数値を**ぜんぶ書くと、仕様書になって逆にイメージが湧かなくなる**。
具体性とは数値の量ではなく、**読者の頭に絵が浮かぶこと**。

実例（2026-09、07ランニング初心者）。NHSの「Couch to 5K」を調べて、
週数・頻度・到達時間・各週のインターバル秒数まで全部わかったので全部書いた。読めなくなった。

**やりすぎ（数値7個）**

> 「Couch to 5K」は、9週間かけて週3回走り、最終的に30分続けて走れるようになることを
> 目標にしたものです。最初の週は「1分間走って、1分30秒歩く」を7回繰り返す内容から
> 始まります。（次の見出しで）2週目は「1分30秒走って、2分歩く」を5回と…

**直したもの（数値2個）**

> 「Couch to 5K」では、最初の週に走るのは1回あたり**1分**だけです。歩きをはさみながら、
> **9週間**かけて**30分**続けて走れるところまで持っていく組み立てになっています。

残した数字は「1分」と「9週間で30分」だけ。**この2つの対比が絵を作る**。
「走るのは1分でいい」は読者の思い込みを裏切るし、「1分が30分になる」は道筋が見える。
1分30秒・7回・5回・週3回は、読んでも何も変わらないので落とす。

**残す数字の選び方**

- 読者の思い込みを裏切るか（「走るのは1分だけ」）
- 読んだあとの行動が変わるか
- 覚えて人に言えるか

この3つに当てはまらない数字は、出典が取れていても書かない。
インターバルの秒数、回数、セット数などの手続きの細部は落としてよい。

---

**手順・持ち物・確認事項の具体性は出典なしで書いてよい。**
「靴下を履いて試着する」「左右両方の足で確認する」「見学や体験利用があるか確認する」など、
効果を約束しない実務情報は、記事の実用性を支える部分なので削らない。

### 締めのパターン

- 「〜なら、○○を試してみるといいかもしれません」（具体的アドバイス）
- 「〜が大事です。それだけです」（シンプルに切る）
- 「〜については別記事で詳しく書きます」（次の誘導）

## 運動後ケアへの導線ルール（COSS専用）

このブログは「運動する人」に「スキンケア商品」を自然に知ってもらうことが目的。

> **2026年9月改訂。** 旧版は「運動と肌の関係を科学的に書く（血行促進→肌変化、汗→毛穴詰まり）」
> と指示していた。これは `yakkihou.md` が禁止している因果の直結そのもので、
> 旧記事の「血流が増えるので肌がきれいになる」はここから生まれていた。
> 矛盾していたので、こちらを直した。**迷ったら yakkihou.md と evidence-rules.md が優先。**

1. **記事本文中で1回** — 汗や皮脂が肌に残った状態について触れる。
   血行・代謝と美容効果を因果でつながない
2. **専用セクションで1回** — 運動後のスキンケアの一般的な手順を書く。
   商品の前に、紫外線対策・こすらない・洗いすぎないといった一般論を一段置く
3. **商品紹介は手順の自然な流れから** — 「時間がないときのショートカット」として紹介する。
   不安を作ってからつながない

商品紹介の基本形:

```
[場面描写（帰り道、朝ヨガ後など）] + [課題（時間がない/荷物が多い）]
→ 「そういう場面で使いやすいように開発したのが〜」
→ [商品名 + 1文で何ができるか + 価格]
→ [リンク]
```

## 口語でくだけさせない

旧版は馴れ馴れしい口語で人間味を出そうとしていた。リライト版はこれを全部消している。

**旧版にあってリライト版で消えた表現:**

> 「でも大丈夫。」「これ、ほぼ確実に翌日動けなくなります。」「これだけです。」
> 「わかります。疲れているときはとにかく何もしたくない。」「正直しんどい。」
> 「地味に効きます。」「まずはここを使い倒しましょう。」

企業名義の記事なので、丁寧語を崩さない。人間味は**語尾のバリエーション**で出す
（`yakkihou.md` の「語尾を回して単調さを避ける」）。

`scripts/check_article.py` で機械チェックしたあと、以下を目視で確認する。

- [ ] 「——」が使われていないか
- [ ] 「安心してください」「さあ〜しましょう」がないか
- [ ] まとめが箇条書きになっていないか
- [ ] 商品紹介が唐突に「便利なのが〜」で始まっていないか
- [ ] 結びが「輝く未来」系の抽象的な応援で終わっていないか
- [ ] **各段落の長さに多少のバラツキがあるか**（機械では拾えない。必ず人が見る）
- [ ] 全セクションが同じ形式になっていないか
- [ ] 馴れ馴れしい口語（でも大丈夫／わかります／正直しんどい）が入っていないか
- [ ] 不安を煽ってから商品につないでいないか
