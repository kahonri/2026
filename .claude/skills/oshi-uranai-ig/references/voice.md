**生成前に必ず読む。** `check_ig.py` が機械チェックできるのはここに書いたことの一部でしかない。残りは書き手が判断する。

## 0. 一番大事な原則：素材のないブロックは書かない

2026-09-07のフィードバックで特定された、AI臭の**根本原因**。

> 実測データや実体験がある部分（①②＝星の流れ）は「まだいい」。
> 素材ゼロで埋めた部分（⓪⑤⑥）だけが「当たり前のことしか言っていない」と評価された。

素材がないと、**何にでも当てはまる言葉**で埋めてしまう。何にでも当てはまる＝誰の話でもない。だから刺さらない。

**ルール：**
- ③（私に起きたこと）の素材を**先に**取る。取れるまで⓪⑤⑥を書き始めない。
- ⓪⑤⑥は、③に出てきた**具体的な名詞・動詞を流用して**書く。独立して書かない。
- 素材が取れないブロックは、**抽象語で埋めずに空欄のまま出す。** 空欄はミスではない。抽象語で埋めるほうがミス。

---

### 補足：素材＝出来事ではない（2026-09-12）

「③の素材が取れない」＝「先週なにも起きなかった」ではない。
**条件つきの自己観察は素材になる。**「話しているときだけ出る」「文字なら出ない」「大勢のときほど出る」。

抽象に落ちるのは、条件が無いとき。

| | |
|---|---|
| ✕ | 私は素直なところがあります（条件なし・自称） |
| ◯ | 話しているときだけ、言葉の裏が読めません。LINEやメールなら読めます（条件2つ） |

**「そのまま受け取る」より「裏が読めない」。** 前者は何が出る／出ないのか主語が立たないまま文が続く。
後者は次の行を同じ動詞（読める）で受けられるので、読者が一度も止まらない。（2026-09-12・実投稿で差し替え）

型の使い方は設計書3-2（性質・自己観察型）。**④だけは、どちらの型でも省略しない。**

## 1. 禁止パターン6つ

星野さんが実際に名指しした4つ。すべて2026-09-07の私の草稿から。

### ① 抽象名詞を、読者の生活の主語にする

| | |
|---|---|
| ✕ | いま、埋めようとしている**空白**はありませんか |
| ✕ | やる気より先に、**順番**がいる |
| ◯ | 今週、前倒しでやっておこうとしてること、ないですか |
| ◯ | やることリストは書いた。一個も消えてない |

**判定基準：その言葉を、読者が生活の中で実際に口に出すか。**
「私は空白を埋めようとしている」と考える人はいない。「予定が空いてるとソワソワする」と考える人はいる。

抽象名詞は**具体物に置き換える**。メール／リスト／線を引く／閉じる／開かない。

### ② 構造を予告して、抽象語で受ける

**予告そのものは悪くない。受けが抽象だと死ぬ。**

| | |
|---|---|
| ✕ | **聞きたいのは一つです。**その**空白**、木曜まで空けておけますか |
| ◯ | **そこで考えてほしいのは**、「どうやったら進むか」ではなくて、「これ、そもそも今のやり方で合ってる？」 |

◯は2026-08-31投稿の7枚目で、**実際に出荷されている。** 予告のあとに来るのが「人が頭の中で実際に言う台詞」なら成立する。「空白」のような抽象名詞が来ると成立しない。

判定は、予告の有無ではなく**その直後**を見る。

### ③ 対句の両側が、どちらも抽象

| | |
|---|---|
| ✕ | あなたの**問題**ではありません。**週の形**です（両側とも抽象） |
| ✕ | 意地悪で止めてくる星じゃない（星野さんが手で直した唯一の行） |
| ◯ | **「どうやったら進むか」**ではなくて、**「今のやり方で合ってる？」**（両側とも具体的な独り言） |

対句そのものは禁止しない。◯は2026-08-31の7枚目で出荷済み。
**両側が具体なら何回でもよい。片側でも抽象が入るなら1投稿1回まで。**

### ④ 敬体の質問で、読者を診断する

> **2026-09-29 解禁（ユーザー指定）。** 敬体の質問で読者に問いかけてよい。問いかけで終わる形もOK。以下は旧ルールの記録。

| | |
|---|---|
| ✕ | 〜ではありませんか／〜おけますか／〜していませんか |
| ◯ | 〜ないですか／〜平気なやつが混ざってます／〜だったりします |

丁寧なのに上から目線になる。診断ではなく、**情景を置いて読者に見つけてもらう。**

### ⑤ 卑下 → 承認の型で組む

2026-09-12に特定。③の素材そのものではなく、**要約の仕方**が「痛い」と評価された原因。

| | |
|---|---|
| ✕ | 反応が遅くて、すぐ忘れて、抜けている（欠点の列挙）→ 友人に好きだと言われた（承認） |
| ◯ | 「ここは笑うところ」の一段を、たまに飛ばす（仕組みの記述）→ だから冗談をそのまま受け取っていた（原因の発見） |

欠点を並べてから承認で回収する型は、SNSでもっとも痛く見える。読者に気を使わせるため。
**同じ出来事でも、「短所が許された話」ではなく「仕組みが分かった話」として書けば成立する。**

判定：③④を読んで、読者が「そんなことないですよ」と言いたくなったら✕。

**⑤も同じ目で見る。** 2026-09-12の投稿では、③④から承認オチを外したあと、
⑤に「友人に聞いたら、そんなつもりはないと言われた。それで、ほっとしました」の形で再発していた。
**承認オチはブロックを移動して生き残る。** ⑤は読者に渡す枠なので、私の安心で閉じない。

**あわせて：「素直」「純粋」「天然」を自分で名乗らない。** 自称した瞬間に痛くなる。
これらの語は**他人の台詞の中にだけ**置く（「そんなつもりは全くないんだ」と言われた、の側）。
自分の側は動作で書く。「思ったことのほうが先に出る」「文字なら間に合う」。

### ⑥ 星の話で、断定する／後付けで意味づける

2026-09-14に特定。**①②④は素材があるぶん抽象には落ちないが、代わりに「言い過ぎ」で崩れる。**

| | |
|---|---|
| ✕ | たぶん、重くなるのが先に分かっていたんだと思います（**出来事の後付けの意味づけ**） |
| ✕ | 土星の週を越えやすいのは、真面目にやる人じゃなくて、途中でふざけられる人のほう（**占星術的な断定としては飛躍**） |
| ◯ | それくらいのくだらなさが、今週はちょうどいい気がしています（**私の側の感じ方として置く**） |

- **落差は説明しない。** 重い星の話をしている机に、アホみたいな眼鏡が出ている。その落差がその回の面白さなら、
  「なぜ置いてあったか」を星で回収した瞬間に消える。**出来事を占いのために意味づけない。**
- 強いコピーほど、**占星術の一般則として言い切っていないか**を見る。言い切りたくなったら「私はこう読む」に戻す。
  このアカウントは教える人ではなく、使っているところを見せる人（設計書1章）。

**星と星座の役割を混ぜない。**

| | |
|---|---|
| ✕ | 水星は、人とのやりとりの言葉を担当する星です |
| ◯ | 水星は、言葉や伝達を担当する星。天秤座では、とくに人とのやりとりに意識が向きます |

**天体の性質も断定しない。** その週の③に密着する言い方へ寄せる。

| | |
|---|---|
| ✕ | 土星は、まだ形になっていないものを出させない |
| ◯ | 止められるというより、「まだこれでいいのか」と確認させられる感じ |

## 2. 語彙

### 2-1. 抽象名詞リスト（2026-09-29 緩和：文の流れで違和感がなければ複数あってもよい。多すぎないかの目安として使う）

空白／余白／順番／違和感／輪郭／本質／構造／状態／感覚／意識／自分軸／エネルギー／タイミング／バランス／ステージ／フェーズ／方向性／可能性／選択肢／価値観／距離感／温度感／解像度

### 2-2. スピリチュアル語（全面禁止）

宇宙／波動／引き寄せ／魂／本来のあなた／ステージが上がる／浄化／覚醒／潜在意識／ハイヤーセルフ／ご縁／メッセージが届く

設計書11章の世界観（小さな個人誌・写真エッセイ）と正面から衝突する。

### 2-3. 構造予告フレーズ（全面禁止）

聞きたいのは／大事なのは／ポイントは／理由は◯つ／まとめると／要するに／整理すると／結論から言うと／ここで考えてほしいのは

### 2-4. AI定番の接続・文末（多用禁止）

とはいえ／一方で／そして何より／〜という観点では／〜だなと感じました／〜ではないでしょうか／〜と言えるでしょう

## 3. リズム

- **短文を混ぜる。** 全部が整った長さだと機械に見える。8〜15字の文を各ブロックに最低1つ。
- **文末を連続させない。**「です。」「ます。」が3回続いたら1つ崩す。体言止め・「〜けど。」「〜かも。」を混ぜる。
- **三点の番号列挙（①②③）は使わない。** 同じ内容を地の文で書く。
- **口語を恐れない。**「〜してる」「〜ってやつ」「〜じゃないですか」「平気」「たぶん」。設計書の世界観は静かだが、堅くはない。

## 5. ブロック別の注意

| # | 注意 |
|---|---|
| ⓪ | **言い当て型でも、必ず具体物を入れる。** 状態の描写（「何も始まっていない」）ではなく、情景（「リストは書いた。一個も消えてない」）。⓪が抽象化した瞬間に、ただの占いアカウントに戻る |
| ① | 天体名・度数・時刻は具体的に出してよい。ここは素材があるので抽象化しにくい |
| ② | 「つまり」で始めない。①の言い換えではなく、生活のどの場面で起きるかを書く |
| ③ | 固有名詞を1つ。日数・時刻・物の名前。**ここが空なら投稿を出さない** |
| ④ | ③の言葉を引き継ぐ。新しい抽象語を持ち込まない |
| ⑤ | ③④で使った具体名詞を、読者の生活に置き換える。診断しない |
| ⑥ | 番号列挙にしない。動作を1つずつ、地の文で |
| ⑥ | **期限を置かない。** 「金曜までに」は、その日にアスペクトが正確になることを行動の締切にすり替えている。占星術による行動指示になる。**月相は締切ではなく「そこでもう一度見る日」として置く**（2026-09-14） |
| ⑥ | **媒体を選ばない動詞で閉じる。** 「もう一度開いてみて」はメールなら合うが、LINE・写真・片づけたい部屋の一角には合わない。**「もう一度確認してみてください」**なら全部に当てはまる（2026-09-14） |
| ⑥ | **分岐は、読者が自分の手元で目で確かめられるもので切る。** ✕「意味、変わりますか。変わらないなら、重くしていたのは『言い方』だけかもしれません」→ 何を見れば判定できるのか分からない。◯「ふざけた声で読んでも**用件が伝わる**なら、重く書かなくていい話です」（2026-09-14） |
| ⑥ | **分岐した先の行き先を、片方ずつ決める。** 両方の読者に「送っていい」と「土曜にもう一度確認」がかかると、**いま何をするのかが決まらない。** ◯ 伝わるほう＝そのまま送る（今）／軽く言えないほう＝今週は寝かせる→土曜の上弦でそれだけ確認する。**日付は片方の枝にだけ紐づける**（2026-09-14） |
| ⑤ | **主張ではなく癖として置く。** ✕「重く書くほど丁寧だと思っているところ、私にはあります」→ ◯「私はつい、重く書くほど丁寧だと思ってしまいます」（2026-09-14） |

## 5-2. ◯の実例（2026-08-31投稿・**9枚すべて草稿のまま出荷された**）

手本はこれ。避ける方向のルールだけでなく、寄せる先として読む。

> **7枚目（⑤）**
> あなたが今、進まないでいることは何ですか？
> そこで考えてほしいのは、「どうやったら進むか」ではなくて、「これ、そもそも今のやり方で合ってる？」
> 土星に止められているときは、アクセルを強く踏み直すほど、うまくいきません。

> **8枚目（⑥）**
> 紙でも、スマホのメモでもいいので、これだけ埋めてみてください。
> ＿＿＿＿＿＿ だから、私は止まっている。
> 「時間がない」で埋まったら、もう一段だけ掘ってみる。何に時間を使っているせいで、ないのか。
> そこが、あなたの答えです。

読み取れること：
- **問いは短く、答えは読者の口語で書く。**「これ、そもそも今のやり方で合ってる？」は完全な話し言葉
- **決め台詞は1投稿1回なら効く。**「そこが、あなたの答えです。」は8枚目に1回だけ
- **具体物を必ず置く。** 紙／スマホのメモ／時間がない／アクセル
- 抽象名詞は「方向性」1語のみ（6枚目）。それ以外はゼロ

## 7. しいたけ占いから借りるもの（2026-09-15・実物を読んで抽出）

出典：`shiitakeuranai.jp` 週間運勢 2026-09-14週（牡羊・牡牛・蟹・蠍）を実読。

### 借りる4つ

1. **言い切る前に前置きを一枚はさむ。**「怒らないで聞いてほしいのですが」「美談を語りたいわけではないのですが」「ひとつ話をしたいのですが」。
   断定を避けるためではなく、**読者が身構える時間を作る**ために置く。当たらなかったときに離脱されない保険にもなる
2. **星の動きを、読者が自分の体で確認できるものに翻訳する。**
   例：「夏から秋に向かう時って、急に『今年も、もうすぐ終わりなのかも』みたいな妙な寂寥感が出て、夏の間に隠しておいた疲れが出やすかったりする」。
   → ②「日常の言葉に翻訳」のお手本。季節・体調・生活動線に落とす
3. **比喩は必ずモノにする。** 機嫌が悪い＝「営業中の看板はかかっているのに、シャッターが半分降りている」。
   心の状態を心の言葉で言い換えない
4. **締めに小さな体の指示を置く。** 手を洗う／変な顔をキープしたまま「楽しくなってきました」と言う。
   → ⑥受け皿が「メモに書き出す」ばかりで保存0が続いている件（STATE §7-5）の直接の処方

### 借りないもの

- **惑星名を消すこと。** しいたけ占いは週間運勢で惑星名を一度も出さず、代わりに色（「『すげー楽しいっす』の黄色が出ていました」）と「今週、全星座に『モチベーション管理』の宿題が発生しそう」という共通課題で星の流れを表現している。
  推しの占い子は**読み方を教えるアカウント**で、誕生日メールの設計自体が「月日＝太陽ひとつ／生まれ年＝木星と土星」という情報の段差で成立している。惑星名を消すと商品が消える
- **占い師個人のキャラ芸**（口癖・独自の色体系）。真似ると模倣に見える
