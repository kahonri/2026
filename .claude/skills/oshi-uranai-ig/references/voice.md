# 推しの占い子 IG 文体規則

**生成前に必ず読む。** `check_ig.py` が機械チェックできるのはここに書いたことの一部でしかない。残りは書き手が判断する。

---

## 0. 一番大事な原則：素材のないブロックは書かない

2026-09-07のフィードバックで特定された、AI臭の**根本原因**。

> 実測データや実体験がある部分（①②＝星の流れ）は「まだいい」。
> 素材ゼロで埋めた部分（⓪⑤⑥）だけが「当たり前のことしか言っていない」と評価された。

素材がないと、**何にでも当てはまる言葉**で埋めてしまう。何にでも当てはまる＝誰の話でもない。だから刺さらない。

**ルール：**
- ③（私に起きたこと）の素材を**先に**取る。取れるまで⓪⑤⑥を書き始めない。
- ⓪⑤⑥は、③に出てきた**具体的な名詞・動詞を流用して**書く。独立して書かない。
- 素材が取れないブロックは、**抽象語で埋めずに空欄のまま出す。** 空欄はミスではない。抽象語で埋めるほうがミス。

## 1. 禁止パターン4つ

星野さんが実際に名指しした4つ。すべて2026-09-07の私の草稿から。

### ① 抽象名詞を、読者の生活の主語にする

| | |
|---|---|
| ✕ | いま、埋めようとしている**空白**はありませんか |
| ✕ | やる気より先に、**順番**がいる |
| ◯ | 今週、前倒しでやっておこうとしてること、ないですか |
| ◯ | やることリストは書いた。一個も消えてない |

**判定基準：その言葉を、読者が生活の中で実際に口に出すか。**
「私は空白を埋めようとしている」と考える人はいない。「予定が空いてるとソワソワする」と考える人はいる。

抽象名詞は**具体物に置き換える**。メール／リスト／線を引く／閉じる／開かない。

### ② 構造を予告して、抽象語で受ける

**予告そのものは悪くない。受けが抽象だと死ぬ。**

| | |
|---|---|
| ✕ | **聞きたいのは一つです。**その**空白**、木曜まで空けておけますか |
| ◯ | **そこで考えてほしいのは**、「どうやったら進むか」ではなくて、「これ、そもそも今のやり方で合ってる？」 |

◯は2026-08-31投稿の7枚目で、**実際に出荷されている。** 予告のあとに来るのが「人が頭の中で実際に言う台詞」なら成立する。「空白」のような抽象名詞が来ると成立しない。

判定は、予告の有無ではなく**その直後**を見る。

### ③ 対句の両側が、どちらも抽象

| | |
|---|---|
| ✕ | あなたの**問題**ではありません。**週の形**です（両側とも抽象） |
| ✕ | 意地悪で止めてくる星じゃない（星野さんが手で直した唯一の行） |
| ◯ | **「どうやったら進むか」**ではなくて、**「今のやり方で合ってる？」**（両側とも具体的な独り言） |

対句そのものは禁止しない。◯は2026-08-31の7枚目で出荷済み。
**両側が具体なら何回でもよい。片側でも抽象が入るなら1投稿1回まで。**

### ④ 敬体の質問で、読者を診断する

| | |
|---|---|
| ✕ | 〜ではありませんか／〜おけますか／〜していませんか |
| ◯ | 〜ないですか／〜平気なやつが混ざってます／〜だったりします |

丁寧なのに上から目線になる。診断ではなく、**情景を置いて読者に見つけてもらう。**

## 2. 語彙

### 2-1. 抽象名詞ブラックリスト（使うなら1投稿1回まで、できればゼロ）

空白／余白／順番／違和感／輪郭／本質／構造／状態／感覚／意識／自分軸／エネルギー／タイミング／バランス／ステージ／フェーズ／方向性／可能性／選択肢／価値観／距離感／温度感／解像度

### 2-2. スピリチュアル語（全面禁止）

宇宙／波動／引き寄せ／魂／本来のあなた／ステージが上がる／浄化／覚醒／潜在意識／ハイヤーセルフ／ご縁／メッセージが届く

設計書11章の世界観（小さな個人誌・写真エッセイ）と正面から衝突する。

### 2-3. 構造予告フレーズ（全面禁止）

聞きたいのは／大事なのは／ポイントは／理由は◯つ／まとめると／要するに／整理すると／結論から言うと／ここで考えてほしいのは

### 2-4. AI定番の接続・文末（多用禁止）

とはいえ／一方で／そして何より／〜という観点では／〜だなと感じました／〜ではないでしょうか／〜と言えるでしょう

---

## 3. リズム

- **短文を混ぜる。** 全部が整った長さだと機械に見える。8〜15字の文を各ブロックに最低1つ。
- **文末を連続させない。**「です。」「ます。」が3回続いたら1つ崩す。体言止め・「〜けど。」「〜かも。」を混ぜる。
- **三点の番号列挙（①②③）は使わない。** 同じ内容を地の文で書く。
- **口語を恐れない。**「〜してる」「〜ってやつ」「〜じゃないですか」「平気」「たぶん」。設計書の世界観は静かだが、堅くはない。

---

## 4. 1投稿あたりの回数制限

| 項目 | 上限 |
|---|---|
| 抽象名詞（2-1のリスト） | 1 |
| 「〜ではなく／じゃなくて」の対句（**片側でも抽象が入るもの**） | 1 |
| 決め台詞で段落を閉じる（「それが、あなたの答えです」型） | 1 |
| 敬体の疑問（「〜ますか。」「〜ませんか。」） | 2 |
| 絵文字 | 1（設計書7章） |

---

## 5. ブロック別の注意

| # | 注意 |
|---|---|
| ⓪ | **言い当て型でも、必ず具体物を入れる。** 状態の描写（「何も始まっていない」）ではなく、情景（「リストは書いた。一個も消えてない」）。⓪が抽象化した瞬間に、ただの占いアカウントに戻る |
| ① | 天体名・度数・時刻は具体的に出してよい。ここは素材があるので抽象化しにくい |
| ② | 「つまり」で始めない。①の言い換えではなく、生活のどの場面で起きるかを書く |
| ③ | 固有名詞を1つ。日数・時刻・物の名前。**ここが空なら投稿を出さない** |
| ④ | ③の言葉を引き継ぐ。新しい抽象語を持ち込まない |
| ⑤ | ③④で使った具体名詞を、読者の生活に置き換える。診断しない |
| ⑥ | 番号列挙にしない。動作を1つずつ、地の文で |

## 5-2. ◯の実例（2026-08-31投稿・**9枚すべて草稿のまま出荷された**）

手本はこれ。避ける方向のルールだけでなく、寄せる先として読む。

> **7枚目（⑤）**
> あなたが今、進まないでいることは何ですか？
> そこで考えてほしいのは、「どうやったら進むか」ではなくて、「これ、そもそも今のやり方で合ってる？」
> 土星に止められているときは、アクセルを強く踏み直すほど、うまくいきません。

> **8枚目（⑥）**
> 紙でも、スマホのメモでもいいので、これだけ埋めてみてください。
> ＿＿＿＿＿＿ だから、私は止まっている。
> 「時間がない」で埋まったら、もう一段だけ掘ってみる。何に時間を使っているせいで、ないのか。
> そこが、あなたの答えです。

読み取れること：
- **問いは短く、答えは読者の口語で書く。**「これ、そもそも今のやり方で合ってる？」は完全な話し言葉
- **決め台詞は1投稿1回なら効く。**「そこが、あなたの答えです。」は8枚目に1回だけ
- **具体物を必ず置く。** 紙／スマホのメモ／時間がない／アクセル
- 抽象名詞は「方向性」1語のみ（6枚目）。それ以外はゼロ
