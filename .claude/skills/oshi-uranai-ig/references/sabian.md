## 使い方（設計書6章の階層に従う）

- **節目投稿（新月・満月）だけ**で使う。定例では使わない
- **テーマの出所にしない。** テーマは人間の感情から始める（スキルが守る一行）
- 置く場所は「小さく＝占星術の言葉」の層。1枚目の英字副情報か、終盤の1枚に1行
- 1度ずれると別のシンボルになるので、**度数は必ず実測する**

## 度数の出し方

```python
# 新月・満月の正確時刻における太陽（新月）／月（満月）の黄経から
deg = int(lon % 30)        # サイン内の度数
sabian = deg + 1           # サビアン度数は切り上げ（18°26′ → 第19度）
```
