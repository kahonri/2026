# oshi-uranai-reel

**最初に `oshi-uranai/docs/STATE.md` 冒頭節と `oshi-uranai/docs/brand-concept.md` を読む。** 仕組みの説明は `oshi-uranai/reel/README.md`。

## 2026-10-11 方針改訂（`brand-concept.md` 6章）

- **リールは新規ユーザーとの接点。まずは15〜20秒の短尺をテストする**（これまでの35〜50秒は長すぎる）。JSONの `duration` で尺を指定する（エンドカード約3秒込み）
- **冒頭1〜3秒で興味を引く。** 表紙を日付と星の名前だけで始めない。日常の悩みや問いの一言から入る（例：「好きなことが、わからなくなった？」→ 星の話）。**表紙を問いで始めるには、moon の `theme` に問いを複数行で書き、`date` に星の出来事を小さく置く**（2026-10-11 対応。表紙の小見出し・補足は行数に合わせて自動で位置がずれる。見本＝`reel/specs/2026-10-14_冥王星の逆行おわり.json`）
- **キャプションの最後（ハッシュタグの直前）に、フォローする理由を一文入れる（2026-10-11 ユーザー決定）。** 定型＝「毎週月曜は『今週の星読み』、新月・満月などの節目は前日までに投稿しています。星とカードで自分を読む練習、よかったら一緒に。」。理由：10/11実測でリールはフォロワー以外に届く（新月リール81%）のに、プロフィールアクセス・フォローが0。届いた人に「フォローすると何が届くか」を言う。エンドカードには文字を載せない決まりは維持
- **表紙のタイトルだけは言い切ってよい（2026-10-21 ユーザー決定）。** よくあるバズる冒頭フレーズの型から選ぶ。本文・締めは従来どおり断定しない（締めは自分への問い）。型＝①否定・制止「〇〇、やめてください」／②常識を覆す「実は、〇〇しないほうがうまくいきます」／③失敗回避「〇〇する前に、これだけ確認して」／④対象を絞る「〇〇しているのに、△△な人へ」／⑤本音・あるあるの代弁「休んでいるのに、休んだ気がしない」／⑥問いかけ・自己チェック「それ、本当に自分で選びましたか？」／⑦答えが気になる「〇〇が続かない理由、実はここです」／⑧結果を先に「〇〇をやめたら、△△が変わりました」／⑨失敗談・告白「私、ずっと〇〇を間違えていました」／⑩検証・比較「〇〇と△△、両方試しました」／⑪数字・範囲「まずは、この1つだけ」／⑫物語の途中から「その一言で、引き受けるのをやめました」。**⑧⑨⑩⑫は実体験が要るので、ユーザーの実話があるときだけ使う。** ⑦⑪は2枚目以降で答え・その1つを必ず出す。見本＝`reel/specs/2026-10-22_水星逆行はじまり.json`（⑤）。**提案の形（2026-10-26 ユーザー決定・カルーセルと共通）＝5〜6案を表にして型の名前を添える／おすすめを1つ、理由つきで／中で答えが要る型は答えの場面を書く**
- **1本につき1テーマ・1メッセージ。** オリジナルのひとことも1つに絞る
- 専門用語より、日常の悩みや問いを入口にする
- **動きを足す**：静止画の切り替えだけにしない（`brand-concept.md` 6章）。根・枝・つた・星座の線など「線が伸びる」絵は `"grow": true` で根元から伸ばせる。芽・花など小さなものは `"sprout": {"box": [...]}` で地面から伸び上がらせる（どちらも2026-10-11 追加・`reel/README.md`）。イラストを頼むときから、伸ばしたい線を無地の下地に描いてもらうと効く
- 投稿4分類（①星読み×自己理解／②タロット×自己理解／③星読み×タロット／④自分の経験）のどれかを決めてから書く

## 手順

1. **系統を決める**：moon／sky／tarot／know／decide／essay（README の表）。`posting-calendar.md` に枠があればそれに従う
2. **素材を実測・取得する**
   - 星の回：日付・星座は `python .claude/skills/oshi-uranai-ig/scripts/month_astro.py --month YYYY-MM` で実測してから書く
   - タロット回：**ユーザーが実際に引いたカード（名前・正逆・デッキ）を共有してもらうまで書かない。** 絵柄が `oshi-uranai/assets/tarot/` に無ければ、Canvaで1枚生成して追加する（一般的なライダー版の構図・ベージュ白グレー黒の線画・文字なし）
   - **タロット回の型（2026-10-05 確定）**：引いたのは私でも、**出たカードは「このリールを見たあなたの今週の1枚」**として出す（私の感想にしない）。流れ＝
     ①伏せたカード＋「このリールを見た／あなたの、今週の1枚。」→ ②今週の星（実測）→ ③「そんな今週の／あなたに出たのは、○○の正位置。」→ ④カードの詳しい解説（学びたい人向け。デッキの絵柄の話もここ）→ ⑤今週のあなたへの読み → ⑥カードを大きく再表示＋「もう一度、カードの絵柄を見てください。」→ 締め「パッと頭に浮かんだことが、今週のあなたへのヒントになります。」
     ⑥の画像は紙背景にカード面を置いた1枚を作って `meaning` の最後に入れる。締めの前に別の問いは置かない（終わりが2つになる）。見本＝`oshi-uranai/reel/specs/2026-10-05_タロット_女教皇_新構成テスト.json`
3. **台本を書く**（JSONの `theme` `message` `questions` など）
   - 星・カードの情報 → **自分への問い**につなげる。断定しない
   - 1行15字以内を目安に `\n` で改行。問いで終わってよい
   - 読んだ人が「占い師に答えを聞きたくなる」ではなく「自分に問いかけたくなる」かを確認
   - **オリジナルのひとことを入れる**（星の出来事にまつわる豆知識・何年ぶりか等）。事実は計算か出典で確かめてから書く。「〜だけ」「初めて」の言い切りは反例がないか確認する（2026-10-11：「天秤座だけが道具」→水瓶座の指摘で撤回）
   - 比喩は中身に戻す・問いはその場で自分に聞ける形・定着した用語（守護星）はそのまま（`oshi-uranai-ig/references/voice.md` 8章＝ユーザー校正から）
4. **設定を保存**：`oshi-uranai/reel/specs/YYYY-MM-DD_スラッグ.json`
5. **確認用の1コマ**：`python oshi-uranai/reel/make_reel.py <spec> --still 秒` で表紙・問い・締めを見る
6. **書き出し**：`python oshi-uranai/reel/make_reel.py <spec>` → 同じ場所に `.mp4`
7. **切り出して実測してから報告**（ffmpegで数コマ切り出し、文字の欠け・はみ出しを見る）。キャプション案も添える

## 守ること

- 最後はエンドカード（自動で付く。外さない。**エンドカード自体には文字を載せない**）
- **節目（新月・満月など）のリールは、締めのあとに自分解説書の案内を1場面入れる**（JSONの `cta`。エンドカードの直前に入る）。文言＝「自分を知るところから、／始めたい方へ。／「自分解説書」受付中／プロフィールのリンクから」（JSONの書き方は `reel/specs/2026-10-11_天秤座新月.json`）（2026-10-11 ユーザー校正で確定）
- 節目のリールは**節目の2日前か前日**に出す。遅くとも当日朝（`posting-calendar.md` ルール2）
- BGMは入れない
- 実体験・引いたカードを捏造しない
- イラストを入れたいときは `images` で差し込む（AI生成イラストも可・色はベージュ白グレー黒）。moon の `message`・`closing` は `{"text","image","ypos"}` でもよい
- **イラストはオーレ・エクセル調。リールには女の子と黒猫を必ず入れる。追加のモチーフ（例：10/11のふくろう）はユーザーがその都度指定する。こちらから勝手に足さない**（2026-10-11 ユーザー指定）。Canvaで生成するときは承認済みの絵（`clips/2026-10-05_reel/01.png`。ふくろうを指定されたら `clips/2026-10-11_reel/00_cover.png`）を見本にする。書き出しは1080×1920の作業用デザインに差し替えてPNG書き出し
- **新月の表紙は細い三日月**（満月に見える丸を描かない）。`cover_image` に三日月入りのイラストを敷き、`"phase": null` でコードの月を消す
