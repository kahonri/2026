# 誕生日投稿（デイリー）生成スキル

## ⚠️ 重要：このスキルは一度だけ実行すること。ループや繰り返しは禁止。

7日分を1回のバッチで生成する（週間占いと同じ日曜運用・翌週分が基本）。

---

## 読みの原理（前提知識）

その人の太陽は、毎年の誕生日に生まれたときの位置へ帰ってくる。
つまり「M月D日生まれの人のこの1年」は、**投稿日当日の空で太陽が受けている配置**を読めばよい。
年・時刻・場所は不要。素材は4層：

1. **性格の軸**＝太陽サイン×デーカン（ストック36本から引く・固定）
2. **この1年の骨格**＝遅い天体（木星・土星が主）→太陽のアスペクト
3. **滑り出しの色**＝速い天体（水星・金星・火星）→太陽のアスペクト（1文だけ）
4. **誕生日の空気感**＝当日の月のサイン（一言添え）

**「この1年」を名乗れるのは2だけ。** 3・4を1年の話として書かない。

---

## 実行手順

### 1. 天体データをスクリプトで計算する

```bash
# 来週分（日曜バッチが通常運用）
python .claude/skills/oshi-uranai-daily/scripts/daily_astro.py --next

# 今週分 / 特定週
python .claude/skills/oshi-uranai-daily/scripts/daily_astro.py
python .claude/skills/oshi-uranai-daily/scripts/daily_astro.py --week 2026-W36
```

計算は oshi-uranai-weekly の Skyfield 環境を流用（APIキー・通信不要）。
出力：各日の太陽サイン・デーカン／年の骨格・滑り出しの色のアスペクト／月のサイン／
イベント（★リール候補）／週冒頭に「木星・土星が効いている誕生日」一覧。

**⚠️ astro.com等のWebFetch読み取りは禁止**（週間スキルと同じ理由）。

### 2. 計算結果をユーザーに確認する（1回だけ聞く）

出力サマリーを提示し「このデータで進めていいですか？」と1回だけ確認する。
ユーザーが手動データを提供した場合はそちらを優先する。

### 3. 性格の軸ストックを読み込む

`oshi-uranai/daily/sun-decans.md` を読み、各日の「ストック「◯◯座・◯◯」」に対応する本文を引く。
**ストックの文言は原文のまま使う（星野さんレビュー済みの文言を崩さない）。**
リライトしてよいのは冒頭の接続1文だけ。

### 4. 7日分の投稿を生成する

**語り口は oshi-uranai-weekly の共通ガイドラインに従う**：短い行で改行／カジュアルな語尾
（〜かもしれません・〜とよさそうです）／専門用語は平易に言い換え／文末は言い切り・ですます・
体言止めのみ（接続助詞止め「〜て。」「〜けど。」禁止、段落末の「名詞＋助詞。」止め禁止）。

**誕生日投稿の固有ルール：**

- 用語を出さない：「デーカン」「ソーラーリターン」「トランジット」は書かない。
  「◯◯座のちょうど真ん中あたりで生まれた人」「誕生日の日、空では〜」と言い換える
- **吉凶を書かない。特に「今年は試練の年」型は絶対に禁止**（誕生日に凶を渡された人は戻ってこない）。
  ハードアスペクトは「テーマ・問い」に変換する
- 木星＝「ラッキーイヤー」、土星＝「我慢の年」の紋切り禁止。
  木星は「広がる・増える方向」、土星は「形になる・積み上がる方向」の言葉で書く
- 本文は「この日生まれの人」を主語にする（あなた／推しのどちらで読んでも成立させる）。
  締めの手渡しだけ「あなた」に戻す
- **キャプション本文に「M月D日生まれ」の文字列を必ず入れる**（Instagram内キーワード検索対策。タグだけに頼らない）

**1日分のフォーマット（250〜350字）：**

```
### M/D（曜）「M月D日生まれの人」

【画像用一行コピー】
（20字前後。その日の骨格 or 滑り出しから1本）

【キャプション】
（0 宛先：今日が誕生日のあなたへ。そして、今日が誕生日の推しがいる人へ。 の型・1〜2行）

（1 性格の軸：ストック原文・80〜100字）

（2 この1年：骨格＝木星・土星が主材料・100〜130字。「〜が育つ1年」の型で言い切りすぎない。
   骨格が「なし」の日は、滑り出しの色＋月を「今年の誕生日はこういう始まり方」として書く。
   速い天体と月は1文だけ添える）

（3 締め：手渡しの一言＋「今日誕生日の人に届けてください」のシェア動線・40〜60字）

（CTA固定文・毎回そのまま）
ここまでは、この日に生まれたみんなの話。
あなただけの流れは、生まれた時間と場所まで見ると変わります。
「推しの占い子」——プロフィールのリンクから。

#M月D日生まれ #誕生日 #誕生日占い #自己理解 #推しの占い子 ＋その日のテーマ関連1〜2個
```

### 5. 省エネリールを1本選ぶ

7日のうち一番シェアされそうな日（★リール候補のある日、または骨格が強い日）を1つ選び、
テキスト動画テンプレ用に書き出す：

```
【省エネリール（M/D分）】
（1行12字前後×4〜6行。画像用一行コピー→性格の軸の要約→この1年の一言→締めの順）
```

### 6. 特別な日のリール台本（★リール候補がある週のみ）

新月・満月・逆行開始/終了・遅い天体の星座入りがあれば、45〜60秒（250字前後）の話し言葉台本を1本生成。
この台本だけで完結すること。天体名は略さない。作れない週はスキップしてよい（月2本で十分）。
