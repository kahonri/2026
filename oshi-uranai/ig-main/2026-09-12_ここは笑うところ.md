## 1枚目（設計書6-2の「帯」を初適用する回）

3つの層で組む。**大＝人間の言葉／帯＝日本語の星／英字＝位置固定**。

### 帯（確定）

```
▌ 乙女座新月 ▐
```

- 白ベタに黒文字、または写真から拾った濃いグレーに白文字。**色は使わない**
- 天王星逆行は帯に載せない（帯は1投稿1本。主役は新月）
- 大コピーの 50〜65% サイズ。大コピーの行間に挟む

### 英字（位置固定・下部）

- 通常案：`NEW MOON IN VIRGO` / `SEP 11`
- サビアン案：`NEW MOON IN VIRGO 19°` / `A SWIMMING RACE`

### 大コピー（確定・22字）

```
「ここは笑うところ」を、踏み外すことがある。
```

- 「踏み外していた」（過去・終わった私の話）ではなく**「踏み外すことがある」**（現在の習性）。
  読者が自分に当てはめられる。告白型と言い当て型の中間に置くための現在形。
- 「ことがある」は保険表現ではない。**「いつもではない」が事実として必要**なので落とさない。
- 「を、」で自然に折れるので、そこに帯を挟む。

### 組み

```
┌──────────────────────┐
│   〔水のある写真〕        │
│                      │
│  「ここは笑うところ」を、 │
│  ▌ 乙女座新月 ▐        │
│   踏み外すことがある。    │
│                      │
│      NEW MOON IN VIRGO│
│      SEP 11          │
└──────────────────────┘
```

※句点は入れる（カギ括弧が先にあるので、無いと文が終わって見えない）。
※カギ括弧と帯が近いので、帯は括弧より**細く**。うるさくなるなら帯をコピーの下へ逃がす。
