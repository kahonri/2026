## いまのルール（2026-09-30 更新：毎週月曜を定例に）

1. **毎週月曜19:00は定例。**4本柱（今の星40／自分を知る25／自分で決める20／自分を推す15）から1本。カルーセルでもリールでもよい
2. **節目は必ず出す**（新月・満月・逆行の開始/終了・外惑星のサイン移動・二至二分）。**節目が日・月・火に当たるときは、月曜の投稿として出して定例と兼ねる**（3日続けて出さないため。定例は週の予告として先に出してよい）
3. **水〜土の節目と、告知などのイレギュラーは、月曜とは別の日に出す**
4. **リールは必須**（KPI＝フォロワー増）。`oshi-uranai-reel` スキル＋ `reel/make_reel.py`（6系統）。最後は必ずエンドカード
