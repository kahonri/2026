# 無料と有料は、何がどう違うのか（検討中・要判断）

作成：2026-09-08　状態：**星野さんの確認待ち。確定したら relaunch-copy.md と natal-reading-design.md に反映する**

きっかけ：「無料鑑定の直後に、同じような鑑定を有料で申し込むとは思えない」「付加価値が
『モヤモヤを形にする』だけだと弱い」という問題提起（2026-09-08）。

---

## 0. 先に結論

**中身はすでに違う。違っていないのは"説明"のほう。**

有料の6ブロック型には、無料鑑定に**一つも入っていない要素**が4つある。

| 要素 | 無料 | 有料 |
|---|---|---|
| トランジット（**なぜ、いま**そのモヤモヤが起きているか） | ✗ なし | ✓ ブロック3 |
| 見立ての言い切り（「あなたのモヤモヤはこういうことだと私は見ます」） | ✗ なし | ✓ ブロック4 |
| 行動（今週からできること2つ） | ✗ なし | ✓ ブロック5 |
| 質問1往復・返金保証 | ✗ なし | ✓ |

無料は**出生図だけ**を読む。つまり「あなたはどういう人か」で終わっていて、
**時期の話も、行動の話も、一切していない。**

にもかかわらず、商品の説明は「**モヤモヤに言葉がつく体験**」の一点だけを名指ししている。
これは4つの要素のうち、いちばん弱くて、いちばんAIに近い部分。
**弱いのは商品ではなく、看板。**

ただし「弱い」という感覚自体は正しい。理由が2つある。

1. 上記のとおり、**看板が中身の一番弱い部分を名乗っている**
2. **タロットが売り物に入っていない。** アカウント名は「星読み×タロット」なのに、
   売り物にカードがなかった。**カードは唯一、AIに代替されにくい部分**

→ 打ち手は「作り直す」ではなく、**①説明を中身に合わせる ②タロットを上位プランの核にする** の2つ。
テキスト鑑定にカードは入れない（§2）。**テキストは「無料を受けていない人」への入口商品**なので、
無料との差別化はターゲットの整理（§1）で解決している。

---

## 1. 3層に整理する

| | **無料お試し** | **有料テキスト鑑定** | **上位プラン（対面つき）** |
|---|---|---|---|
| 答える問い | **私はどういう人か** | **その私が、いま何を選ぶべきか** | **それを、一緒に考える** |
| 使うもの | 出生図のみ | 出生図＋**トランジット** | 左＋**タロット**＋対面30分 |
| 時期の話 | なし | **あり**（なぜ今か・いつ動くか） | あり |
| 行動の指示 | なし | **あり**（2つだけ） | その場で決める |
| 往復 | なし | 質問1往復 | 対面で時間内なら何度でも |
| 分量 | 1,000字 | 約2,200字 | ＋30分 |
| 価格 | 0円（16名限定・募集終了） | **3,500円** | **8,000円** |
| 誰に出すか | 2年前の申込者16名 | **無料を受けていない人**（IG新規・誕生日メールの名簿） | **無料を受けた9名**／テキストのリピーター |

### ここが今回いちばん大事な整理

**有料テキスト鑑定のターゲットは、無料を受けた9名ではない。**

テキストを読み終えた人に次に出すべきは「もっと長いテキスト」ではなく、**話すこと**。
度合いの違いではなく種類の違いなので、「さっきと同じもの」にならない。
過去に星読み＋タロットの対面マンツーマンを5,000円でやっていた実績とも接続する。

→ **9名にセールスDMは送らない。** 送るとしたら感想の掲載許可のお願いだけ（売らない）。そして感想をもらった人にはすでに送り済み。

---

## 2. タロットをどこに入れるか

対面のみ。星読みの内容に厚みをもたせるように引く。

---

## 3. 看板の書き換え

### いまの説明
> 売っているのは占いではなく「モヤモヤに言葉がつく体験」

→ これは**入口の約束**（フォームにモヤモヤをそのまま書ける、という体験）として残す。
中身の約束は別に立てる。

### 中身の約束（案）

**「いま何を選ぶべきか」に、答えます。**

### 商品名

**パーソナル星読み鑑定**（据え置き）。テキストにタロットは入らないので、看板と中身はずれない。

## 4. 工数と価格の検算

## 5. 確定（2026-09-08）

| # | 決めたこと |

| 1 | **タロットは対面のみ。** テキスト鑑定には入れない。星読みの内容に厚みをもたせるように引く |
| 2 | **上位プラン 8,000円**＝テキスト鑑定＋タロット＋対面30分（時間内なら何度でも聞ける）。**9名の出口はこちら** |

| 6 | テキスト鑑定の構成は6ブロックのまま**変更なし**（約2,000字） |
