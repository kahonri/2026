## 1. ブランド（2026-10-11 方針改訂。原本＝`brand-concept.md`／旧原本＝`archive/brand-concept_2026-09-29.md`）

- **目的**：将来、星読みとタロットを活用した**自己理解講座**を販売する。フォロワー自身が星やカードを読み解き、自分の価値観・才能・本音を理解する楽しさを伝える
- **フォロワーの理想像（2026-10-22 ユーザー決定）**：**「人に合わせるのが上手な人が、自分の気持ちも後回しにしなくなる」**。「このアカウントをフォローしている私」が素敵だと思える理由をつくる。占星術そのものを理想像にしない。キャッチフレーズには長いので外に出す一言は別途。企画・原稿の判断基準にする
- **言葉シリーズ（2026-10-22 ユーザー決定）**：わたししか**選べない**言葉＝偉人・著名人・経営者などの格言を選んで出す。出典は本人の著書・記事・インタビューまで確認できたものだけ／言葉だけの画像にしない（選んだ理由＝自分の文章を主に）／本人の写真は使わない。詳細＝`brand-concept.md`
- **ターゲット（仮説）**：30〜50代の、自分やこれからの生き方を見つめ直したい女性。周囲の期待を優先して本音がわからなくなる／占いは好きだが当たる・当たらないだけでは物足りない／自分でも読み解けるようになりたい
- **役割**：星読み＝自分の輪郭を知る／タロット＝今の自分を見つめる／自己理解＝自分の言葉で答えを見つける
- **投稿の4分類（2026-10-11〜。旧4本柱は廃止）**：①星読み×自己理解35%（**今週の星読み・新月満月などの節目も含む**。今の星を入口に出生図の読み方へつなげる）／②タロット×自己理解25%／③星読み×タロットの実践25%／④自分の経験・占いへの考え方15%（**芯は原点の話＝「人にどう思われる？」から「私はどうしたい？」へ**。仕事・日常・星読み・タロット・AI・ドラム）
- **形式の役割**：リール＝新規との接点（**15〜20秒の短尺をテスト**・冒頭1〜3秒でつかむ・1本1メッセージ・専門用語より日常の悩みや問いから）／カルーセル＝理解・保存・信頼（最後は読者への問い）／ストーリーズ＝関係づくり・講座のニーズ調査
- **30日間の検証**：2026-10-11から、投稿テーマと表現方法を検証して成果の高い形式に寄せる。開始時点の数値を記録しておく（未取得）
- **入口と伝え方（2026-09-30 ユーザーがピン止め投稿で確定）**：
  - 抽象的な理想（「私はどうしたい？を見つける」）より、**具体的な悩みの場面から入る**（人の反応を先に考える／同じところで何度も迷う／その場では合わせたけれど、あとから引っかかる）
  - **答えを急がせず段階をつくる**：自分の気持ち・反応を知る → 迷う理由を考える → 自分に合う選び方を試す。「すぐに答えが出なくても、まずは『私は今、どう感じている？』から」
  - **占いの役割を具体的に言う**：生まれた日の星＝自分の特性や価値観を考える手がかり／今の星の動き＝日々を振り返る問い／タロット＝今の気持ちや状況（周囲との関わり）を振り返る手がかり。どれも**自分の経験と照らし合わせて**読む
  - 共感で終わらせず、**今後読めるものと、日常に持ち帰れる視点**まで示してフォローにつなげる
- **意味は言い切る。答えは読者に選んでもらう。未来は言い切らない（2026-10-27 ユーザー決定・旧「断定しない」を改訂）**：言い切る＝星・カードの意味と読み方／生まれ持った性質／今週の一歩。読者が選ぶ＝その人の答え（自由回答ではなく「1・2・3のどれ？」「AとBのどっち？」の形）。言い切らない＝「未来はこうなる」・吉凶・脅し・他人の気持ち・「このカードだから絶対」。
  チェック＝**読んだ人が1つ選べる／自分で答えられる形になっているか**
  - **補足（2026-10-07 ユーザー）**：NGなのは「占い師が出した答えを、その人の正解として渡す」こと。生まれ持った星の配置からその人の性質（得意・苦手、長所・弱点）を示し、それを活かすことで本来のその人が花開く、という意味での「あなたにとって最短で最適の道」はOK。正解の出どころが占い師ではなく、本人の生まれ持ったものにある
- **使わない言い回し（2026-10-07 ユーザー）**：「理由がわかると、次に迷ったとき、自分に聞けることが増えていく」系。しっくりこない。代わりに、文章（キャプション）では「理由が見えると、同じところで迷ったときに、私（あなた）に合った選択ができるようになる」。「最短で最適の道」は画像の見出し向きで、地の文に置くとコピーっぽく浮く
- **感想の掲載**：無料お試し鑑定の感想9件は、全員から掲載許可を取得済み（2026-10-07 ユーザー確認）。10/7投稿の5〜9枚目に使用
- **二人組（私＋推しの占い子ちゃん）は保留。使わない**
- **文体の緩和**：問いかけで終わってよい（自由回答より選ぶ形を優先・2026-10-27）／敬体の質問でもよい／抽象語は流れに違和感がなければ複数あってよい（`voice.md`・`check_ig.py` 反映済み）
- **見た目はリールの世界観に寄せる（2026-10-22 ユーザー決定）**：投稿一覧（グリッド）の暗い夜空の投稿と、リールのベージュの絵が違いすぎて、リールから来た人が同じアカウントだと思えないため。**投稿の表紙（1枚目）もベージュの紙＋女の子と黒猫**にする。中のページの文字の組み方はそのままでよい。順番＝①リールをグリッドに出す（**2026-10-22 ユーザー実施済み・過去分も**）→②次の投稿から表紙を変える（初回＝10/24 牡牛座満月）→③余裕があるときにピン止め投稿の表紙を作り直す。暗いデザインを残すなら特別な回だけに絞る（未決）
- **ビジュアル**：自分で撮った写真・AI生成画像・AIイラスト・インフォグラフィックを使う。イラストは**リールには女の子と黒猫を必ず入れる。追加のモチーフ（10/11のふくろうなど）はユーザーがその都度指定する（2026-10-11）**。色は**ベージュ・白・グレー・黒**
- **タロット1枚引き**は、ユーザーが実際に引いたカードを共有してから作る。実体験も捏造しない（3枚から1枚も同じ）
- **自分の話・ほかの人の話の線引き（2026-10-27 ユーザー決定）**：自分の話と出生図はほぼ全部出してよい。ほかの人が出てくる話は**関係と場面まで**（名前・職場名・特定できる出来事は書かない）／**その人が読んでも嫌でない書き方**にする／**お客さんの話は本人の許可を取ったものだけ、本人とわかる情報（名前・年齢・職業・住んでいる場所など）を書かずに使う**。リポジトリはPUBLICなので、原稿（`ig-main/`）の段階から特定できない形で書く。鑑定文そのものは `kantei/` だけ／Claudeは、ユーザーが話していない他人の行動や台詞を推測で足さない／迷ったら出さない。最終判断はユーザー

- **カルーセル**：（⓪掴みは任意）①今の星 → ②日常の言葉 → ③私に起きたこと → ④私はどう読んだか → ⑤あなたの場合は → ⑥持ち帰り → 最終枚。**2枚目は星の話から入ってよい（2026-10-11 ユーザー決定。新規の人は星の話で読み進める。用語には意味を一言添える）**。

- **節目（新月・満月・逆行など）の投稿日（2026-10-11 ユーザー決定）**：節目の**2日前（理想）か前日**。遅くとも当日の朝。**翌日以降には入れない**。2日前〜前日が月曜のときだけ月曜定例と兼ねる。それ以外の節目と告知などのイレギュラーは別の日。ルールの本体は `posting-calendar.md`
- **原稿とGoogleカレンダーは作業ごとに分ける（2026-09-30）**：同じ日にフィード投稿とストーリーズがあれば、原稿ファイルもカレンダーの予定も2つ。ストーリーズが複数日なら日ごとに1つ。ファイル名＝`ig-main/YYYY-MM-DD_種類_タイトル.md`（種類＝投稿／ストーリーズ／リール）。カレンダーの色は**ブルーベリー**
- **キャプションの順**：共感 → 今の星 → 私の話 → 今日試せること → 次回の理由。行動の提案は言い切らず、使える場面を添える
