## 1. ブランド（2026-09-29 確定。原本＝`brand-concept.md`）

- **4本柱**：①今の星を読む40%／②自分を知る25%／③自分で決める20%／④自分を推す15%。星の情報は必ず自分への問いにつなげる
- **入口と伝え方（2026-09-30 ユーザーがピン止め投稿で確定）**：
  - 抽象的な理想（「私はどうしたい？を見つける」）より、**具体的な悩みの場面から入る**（人の反応を先に考える／同じところで何度も迷う／その場では合わせたけれど、あとから引っかかる）
  - **答えを急がせず段階をつくる**：自分の気持ち・反応を知る → 迷う理由を考える → 自分に合う選び方を試す。「すぐに答えが出なくても、まずは『私は今、どう感じている？』から」
  - **占いの役割を具体的に言う**：生まれた日の星＝自分の特性や価値観を考える手がかり／今の星の動き＝日々を振り返る問い／タロット＝今の気持ちや状況（周囲との関わり）を振り返る手がかり。どれも**自分の経験と照らし合わせて**読む
  - 共感で終わらせず、**今後読めるものと、日常に持ち帰れる視点**まで示してフォローにつなげる
- **断定しない**：「未来はこうなる」「これを選べば正解」「このカードだから絶対」は書かない。
  チェック＝読んだ人が占い師に答えを聞きたくなるか、自分に問いかけたくなるか（後者を取る）
- **二人組（私＋推しの占い子ちゃん）は保留。使わない**
- **文体の緩和**：問いかけで終わってよい／敬体の質問でもよい／抽象語は流れに違和感がなければ複数あってよい（`voice.md`・`check_ig.py` 反映済み）
- **ビジュアル**：自分で撮った写真・AI生成画像・AIイラスト・インフォグラフィックを使う。色は**ベージュ・白・グレー・黒**
- **タロット1枚引き**は、ユーザーが実際に引いたカードを共有してから作る。実体験も捏造しない
- 今後の商品の方向＝「星読みやタロットを自分でできるように教える教材」

## 4. Instagram運用（詳細は `instagram-operation-design.md`）

- **リール**：1080×1920・無音mp4。`oshi-uranai-reel` スキル＋`reel/make_reel.py`（6系統：新月・満月／今の星／タロット／自分を知る／自分で決める／自分を推す）。**最後は必ず `assets/reel-endcard.png`（字幕なし約3秒・自動付与）**。BGMは不要（必要ならInstagram側で）
- **カルーセル**：⓪掴み → ①今の星 → ②日常の言葉 → ③私に起きたこと → ④私はどう読んだか → ⑤あなたの場合は → ⑥持ち帰り → 最終枚。
  1枚目は3層（大＝読者の言葉24字以内／帯＝星の出来事を日本語で・「星読み」「占い」は入れない／英字）。
  通常回の最終枚は2行だけ（「推しの占い子」「星を読む。カードを読む。そして、自分を読む。」＝タグライン。2026-09-30 統一。旧「星とカードを、毎日の味方に。」は使わない）。告知回だけ案内を足す
- **原稿とGoogleカレンダーは作業ごとに分ける（2026-09-30）**：同じ日にフィード投稿とストーリーズがあれば、原稿ファイルもカレンダーの予定も2つ。ストーリーズが複数日なら日ごとに1つ。ファイル名＝`ig-main/YYYY-MM-DD_種類_タイトル.md`（種類＝投稿／ストーリーズ／リール）。カレンダーの色は**ブルーベリー**
- **キャプションの順**：共感 → 今の星 → 私の話 → 今日試せること → 次回の理由。行動の提案は言い切らず、使える場面を添える
- **やらないこと**：毎日投稿／星座名を1枚目の主役に／予言口調・吉凶断定／巨大ハッシュタグ／不安を煽る
- **天体計算**：`month_astro.py --month YYYY-MM`（月）・`fetch_astro.py --week YYYY-Wnn`（週）。**astro.com等のWeb読み取りは禁止**。曜日も必ず実測
