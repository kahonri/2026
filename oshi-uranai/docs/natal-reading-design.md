# 出生図鑑定（1,000字）設計書

> ⚠️ **2026-08-27 追記：この設計書の前提はずれている。**
> 実際の個人鑑定は「悩み起点のオーダーメイド」で進める方針が確定（ユーザー確認済み）。
> 受付フォーム（https://forms.gle/sPjck7mYNQiT8bm19 ）が
> 「いまのモヤモヤ」「読んでほしいテーマ」「触れてほしくないこと」を聞いており、そちらが本体。
> - 3章の素材選定スコアリングは、量産型の前提。オーダーメイドとは噛み合わない
> - 出生図は「読みの土台」として使い、構成は相談内容に合わせて可変にする
> - 分量・価格・所要時間は作り直す
> 導線の全体像は `birthday-reminder-design.md` 3章を参照。


対象：2年前に無料お試し鑑定へ申し込んでくれた人への再アプローチ用。
生年月日／生まれた時間（不明可）／生まれた場所を入力すると、1,000字程度のテキスト鑑定が出る。

---

## 1. 入力

| 項目 | 必須 | 備考 |
|---|---|---|
| 生年月日 | ○ | 西暦・年月日 |
| 生まれた時間 | △ | 不明のチェックボックスを用意。「だいたい朝／昼／夜」の粗い選択肢も置く |
| 生まれた場所 | ○ | 市区町村レベル。緯度経度＋当時のタイムゾーン（戦後の夏時間 1948-1951 に注意）へ変換 |

### 時刻不明のときの分岐

ASC・MC・ハウス・月の正確な度数が出せない。ここを無理に書くと外すので、**構成そのものを差し替える**。

- 計算は正午（現地時間）で行う
- ASC/MC を使う段落 → 「天体同士の最タイトアスペクト1本」に置き換え
- 月のサインがその日のうちに移動する場合 → 両方のサインを提示し「どちらの感触が近いですか」と問いかける形にする（外れではなく参加に変える）
- 冒頭に一行：「生まれた時間がわかると、ここに"どう見えるか"と"どこへ向かうか"が加わります」→ 時刻を思い出してもらう導線＝再入力＝再訪の理由になる

## 2. 計算する要素

- 10天体（太陽〜冥王星）のサイン・度数・ハウス
- ドラゴンヘッド／テイル（平均交点。`src/lib/nodes.ts`）
- ASC・MC（＋DSC・IC）
- ハウス：**プラシーダス**（`houses.ts` `placidusCusps()`）。時刻が確定しているときはこちらを使う
  - 極圏などで計算できない場合と、時刻不明の場合はホールサイン（`types.ts` `houseOf()`）にフォールバック
  - 週間占いスキルがホールサインなのは、12星座別＝ASCを持たない前提のため。出生図鑑定は事情が違うので分ける
- メジャーアスペクト：合0°／衝180°／矩90°／三分120°／六分60°

オーブ（この鑑定での採用基準）

| 組み合わせ | 合・衝・矩 | 三分・六分 |
|---|---|---|
| 太陽・月が絡む | 8° | 6° |
| ASC・MCが絡む | 6° | 4° |
| その他天体同士 | 5° | 3° |
| ドラゴンヘッド | 5° | 3° |

**1°以内は「タイト」として別枠で最優先に拾う。**

### 2-1. 出生時刻の精度で使える素材が変わる

「夕方5時」のような**概算の時刻**では、ASC・MCは前後30分で7〜8度動く。ここを見落とすと外す。

| | 時刻が分単位で確定 | 時刻が概算（〜30分幅） | 時刻不明 |
|---|---|---|---|
| ASCのサイン | 使う | サイン中央付近なら使う／境界±8度なら使わない | 使わない |
| MCのサイン | 使う | 同上。境界なら「◯座と△座の境目」と書く | 使わない |
| **ASC・MCへのタイトアスペクト** | 加点素材に使う | **加点素材から外す**（オーブが動くので「ほぼ完全」と言えない） | 使わない |
| 天体同士のアスペクト | 使う | 使う（月絡みでも30分で0.3度弱） | 月絡みは慎重に |
| ステリウム・エレメント偏り | 使う | 使う | 使う |
| ハウス | プラシーダス | プラシーダス（カスプ際の天体は注意） | ホールサイン不可・使わない |

概算のときは、素材選びを**時間に依存しないもの**へ寄せる。ステリウム、天体同士のタイトアスペクト、ドラゴンヘッドと天体のアスペクトはどれも安全に使える。

## 3. 素材の選び方（ここが鑑定の設計の中心）

1,000字に入るのは **コア4点＋加点素材1〜2点＋締め** まで。全部書くと散るので、必ず絞る。

### 3-1. コア（毎回かならず使う）

1. **太陽**：**自分の人生の方向性。** 三層に分けて読む
   - サイン → その方向性がどんな**性質**を帯びるか
   - ハウス → **どこで本領を発揮できるか**
   - アスペクト → その人生にどんな**新陳代謝**が起きるか（太陽が他の天体をどう代謝させるか／させられるか）

   太陽が持つそのほかの意味：**女性から見た旦那さん・旦那さんへの態度／仕事／使命／男性／父親。**

   太陽は**獅子座の支配星**。獅子座＝自分を表現する／影響力がある／自分から発信する／自分からエネルギーを出す。
   太陽をどう使っているかを見るとき、この獅子座的な働きが基準になる。
2. **月**：サイン＋ハウス → 心が満たされる条件
3. **ASC**：サイン → 第一印象・佇まい
4. **MC**：サイン（＋10ハウス在住天体） → **社会的役割・仕事でどう見られるか・社会に向けてどんな顔を育てていくか**
   （太陽の「人生の方向性」と混ざらないよう、MCは外向きの顔に限定して使う。**人物評に広げない**——
   「受け止めてくれる人」ではなく「受け止める役割を求められやすい」と、社会での役割の側で書く）

### 3-2. 加点素材（スコア上位2つだけ採用）

| 素材 | 条件 | スコア |
|---|---|---|
| ステリウム | 同一サインに3天体以上 | 3天体=8／4天体以上=10 |
| アングルへのタイトアスペクト | ASC・MCに対しオーブ1°以内 | 10 |
| 太陽とASCの関係 | 同一サイン=同質／対向=補い合い／矩=ねじれ | 7 |
| 月とMCの合 | オーブ3°以内 | 9 |
| ドラゴンヘッドのアスペクト | パーソナル天体・アングルと絡む | 8 |
| 天体同士の最タイトアスペクト | オーブ1°以内 | 6 |
| 逆行天体の集中 | パーソナル天体に2つ以上 | 4 |
| エレメント／モードの偏り | 1エレメントに5天体以上、または欠落 | 5 |

同点なら **オーブが近いほう → パーソナル天体（太陽・月・水星・金星・火星）が絡むほう** を優先。

### 3-2-1. ステリウムは強みにも弱点にもなる（分岐ルール）

ステリウムは「その人だけの濃い部分」なので強みとして書かれがちだが、**密集は圧でもある**。
どちらで書くかは、そのサインに**外から何が当たっているか**で決める。

| 条件 | 書き方 |
|---|---|
| ハードアスペクト（矩・衝）を受けていない | **強み**として書く。「◯◯に集中していて、ここが底力」 |
| アングル（ASC・MC）とハードで絡む | **弱点→克服**として書く。外に出る自分とぶつかっているため |
| 土星・冥王星が集団の外から対向・矩 | **弱点→克服**として書く。処方はその土星・冥王星側から引ける |
| 集団の中に土星・冥王星が含まれる | どちらもあり。在住ハウスが1・4・7・10なら弱点寄り |

弱点で書くと決めたら、**克服方法は必ずステリウムを撃っている側の天体から引く**。
撃っている天体は「敵」ではなく、密集した力の**出口**になる。

例：乙女座4室に火星・天王星・冥王星、そこへ魚座10室の土星が対向
→ 内側（4室）で自分を壊し続ける力を、外（10室）で形にして時間をかけて積む方向へ流す

### 3-3. 「苦手なところ」の取り出し方

弱点は**でっち上げない**。次のいずれかから、実際に出ているものだけを使う。

- 矩（スクエア）・衝（オポジション）で最タイトなもの
- ドラゴンヘッドが受けているハードアスペクト
- 土星が絡むアスペクト、または土星のハウス
- エレメントの欠落（火がない＝勢いで押し切るのが苦手、など）

### 3-4. 対処法は自動で決めない（毎回確認する）

対処法の引き出し方には定石が複数ある。**どれを使うかは配置ごとに変わるので、システムが一つに決め打ちしない。**
素材が確定した時点で候補を並べ、書き手（星野さん）が選んで肉付けする。

処方の引き出し方カタログ：

| 引き出し方 | 使いどころ | 例 |
|---|---|---|
| 対向の星から引く | ドラゴンヘッドの課題 → テイルの既得スキル／太陽 → DSC など | 感情の渦 → 乙女座テイルの「まず手を動かす」 |
| **ソフトアスペクトの星から引く** | **弱点となる天体（群）に三分・六分を送っている星があるとき。** その星のサインとハウスが出口になる | 乙女座3天体すべてに牡牛座の太陽がトライン → 出口は牡牛座＝五感・心地よさ |
| つなぎ役の第三の天体 | スクエアの両端に、どちらともアスペクトを持つ天体がある | 緊張する2天体を金星が緩める |
| 緊張する天体の"良い側"を使う | つなぎ役がいない。天体そのものの長所を出口にする | 土星の重さ → 土星の「型をつくる力」で使い切る |
| ハウス（場所）を変える | 天体の性質ではなく、発揮する場所を変えると収まる | 12ハウスの重さ → 6ハウス的な作業に落とす |
| モードの行動に落とす | 上記が効かないとき。活動＝始める／不動＝続ける／柔軟＝切り替える | 柔軟宮の迷い → 期限を切って切り替える |
| 時間で解く | 土星・冥王星が絡む長期テーマ。今すぐ直すものではない | 「これは年単位でほどけるもの」と伝える |

**「対向の星から引く」の但し書き。** 対向の星は「向こう岸」にあるので、こちら側から取りに行く動作が要る。
その星が**土星だとさらに重く、使い勝手が悪い**。土星のハウスで判断する。10室など、もともと外に出す場所に
あるなら成立する（1966-12-03 の鑑定）。6室・12室など押し返してくる側に回っているときは、この引き方を避け、
**ソフトアスペクトの星から引く**ほうへ切り替える（1965-05-07 の鑑定）。

**ソフトアスペクトの星から引くときの条件。** 弱点が複数天体（ステリウム）なら、**その全員に届いている星**を選ぶ。
一部にしか届かない星を出口にすると、残りが行き場を失う。同サインで並ぶ星は、アングルへのタイトな
ソフトアスペクトがあれば補強として添えられる（例：金星がASCに三分1.23度）。

**出力の運用**：素材確定の段階で、その配置に当てはまる候補を2〜3つ提示する。

```
【苦手と対処】ドラゴンヘッド魚座 × ASC双子座 スクエア
 処方の候補：
  A 対向の星から … ドラゴンテイル乙女座「手を動かして進める力」
  B 緊張天体の良い側 … 魚座の受信感度を「先に感じ取れる」強みとして使う
  C モードの行動 … 柔軟宮同士。決める期限を先に切る
 → どれで書きますか（複数の組み合わせも可）
```

選ばれた処方を段落4に流し込む。候補が1つしか立たない場合もそのまま提示して、確認は必ず挟む。

## 4. 出力構成（1,000字程度）

**目安は1,000字。上下200字は許容。**（2026-09-02 変更。旧「500字／実績700〜800字」は実態と合っていなかった）
削ると鑑定が成立しなくなる要素（ステリウムの展開など）がある場合、無理に詰めない。
「1,000字に収めること」より「必要なことが書かれていること」を優先する。無料お試しからの
再アプローチ用なので、読み応えがあるほうが有利でもある。

実測：kj さん 1,324字／かえさん 1,041字。**1,300字を超えたら削る**。

### 4-A. 標準型（弱点がアスペクト由来）

| # | 段落 | 内容 | 目安 |
|---|---|---|---|
| 1 | 軸 | **太陽＝人生の方向性を最初に名指しする。**「〜していく人生」と一言で置いてから、サインで性質を、ハウスで本領を発揮する場所を添える。ASCサインとの関係（同質／対向／ねじれ）はその方向性の見え方として重ねる | 200字 |
| 2 | 心と立ち位置 | 月サイン×MC。何が満たされ、社会でどう立つか。**方向の話は段落1で済んでいるので、ここでMCを「進む方向」として書かない** | 130字 |
| 3 | らしさの強調 | 加点素材1。「その人にしかない配置」を一点押し | 140字 |
| 4 | 苦手と対処 | 加点素材2＋反転＋処方（3-4で選んだもの） | 350字 |
| 5 | まとめ | 1〜4を畳み直して背中を押す。「まとめると」で入る | 180字 |

### 4-B. ステリウム型（弱点がステリウム由来）

3-2-1 で「弱点→克服」と判定したときはこちら。段落3と4を統合して厚く書く。

| # | 段落 | 内容 | 目安 |
|---|---|---|---|
| 1 | 軸 | 標準型と同じ。**ここで名指しした人生の方向性が、そのまま段落4の着地点になる**ので、抽象語で置かない（「育てる」「積む」「渡す」のような動作の語で置く） | 200字 |
| 2 | 心と立ち位置 | 標準型と同じ | 130字 |
| 3 | 弱点 | ステリウムのサイン・ハウス＋撃っているアスペクト。何が起こりやすいかを2〜3個。**用語を使うなら一文で定義する（7-1(7)）** | 350字 |
| 4 | 克服 | 撃っている側の天体から処方を引く。段落1の語に着地させる | 200字 |
| 5 | まとめ | 標準型と同じ | 120字 |

### 4-C. 段落順は「サインのつながり」で入れ替える（2026-09-02 追加）

4-A・4-B の表の順番は**素材の種類の並び**であって、書く順の固定ではない。
**同じサインを共有する素材は、必ず隣り合わせにする。**あいだに別の素材を挟むと、
読み手が一度その話題から離れて戻ることになり、いちばん濃い部分の印象が薄まる。

いちばん起きやすいのが、**ASCのサインとステリウムのサインが同じ**ケース。
このときは段落2（心と立ち位置）を後ろへ回し、ASC → ステリウムを直結させる。

```
× 軸 → 月・MC → 蠍座ステリウム → 克服 → まとめ
　  （ASC蠍座の話が月・MCで分断される）
○ 軸 → ASC蠍座 → 蠍座ステリウム → 月・MC → 克服 → まとめ
```

段落1で置いた方向性の語を段落4・5で回収する原則さえ守れば、2〜4の順は入れ替えてよい。

### 4-D. 主役以外の素材は捨てる（2026-09-02 追加）

3章のスコアリングで拾えた素材を、全部書こうとしない。
**1段落に載せるアスペクトは1つ。**2つ目を足したくなったら、それは次の鑑定の素材にする。

かえさん（1984-04-26）の例：太陽オポジションASC・火星スクエアMC の2本は、
スコア上は使えるが、蠍座ステリウムと土星コンジャンクトASCで段落が埋まるため**両方落とした**。
落としたことで、残した素材の説明に字数が回って読みやすくなった。

段落1で置いた方向性の語は、段落4・5で必ず回収する。回収できない語を段落1に置かない
（例：1965-05-07 の鑑定＝段落1「時間をかけて確かなものを育てていける人」→ 段落4「直そうとせず、育てる」
→ 段落5「好きなものを手放さずに時間をかけたぶん」）。

**B型ではドラゴンヘッドの段落を落とす。** 軸が2本になって読後に何も残らないため。
1本の鑑定に、掘り下げるテーマは1つだけ。

**標準型（4-A）でも、ドラゴンヘッドが2本目の処方になる場合は段落3ごと落とす。** スコアが最上位でも、
段落4の処方と別の行動指示になるなら、読み手が持ち帰るものが2つに割れる。
「軸を1本に保つ」はB型固有の話ではない。

落としたあと、加点素材1の枠は**無理に埋めない**。次点が世代天体同士のアスペクト（海王星・冥王星など）
しかないなら、個人鑑定では使えないので4段構成（軸／心と立ち位置／苦手と対処／まとめ）にする。
4段構成でも1,000字あれば読み応えは落ちない。

段落間は一行空け。スマホで読むので、**1段落は1〜3文まで**（2026-09-02 変更）。
表の「段落」は内容のまとまりで、見た目の段落はそのなかでさらに割ってよい。
1文だけで一行にする箇所を意図的に作ると、読む速度が落ちて内容が入る。

## 5. 根拠の見せ方

**二段構え**にする。

**(a) 本文にインラインで織り込む** — 例文がこれ。「太陽が"人と関わる部屋"にあるため」「オーブ0.3度のほぼ完全なスクエア」。専門用語は必ずその場で括弧か言い換えを添える。

- アセンダント（第一印象）
- MC（社会での立ち位置）
- ドラゴンヘッド（成長のテーマ）
- **ハウスは「意味＋番号」で書く**（例：「『日々の仕事や習慣』をあらわす6ハウス」。意味の語は短く刈る）。6章の辞書を参照（2026-09-02 変更）
- **アスペクトは名前で書く**（セクスタイル・スクエア・トライン…）。度数・オーブの数値は本文に出さない（次項）

**(b) 本文末に根拠ボックス**（折りたたみ可）

```
──この鑑定の根拠
太陽：射手座／11ハウス
月：水瓶座（MCと合）
アセンダント：双子座
MC：水瓶座
山羊座に3天体（土星・天王星・海王星）
ドラゴンヘッド：魚座（ASCとスクエア／ほぼ完全）
```

本文が主、ボックスは従。ボックスを見なくても読み切れる本文にする。

### 5-1. アスペクトの書き方（オーブは本文に出さない）

**本文には角度を必ず書く。オーブの数値は書かない。**（2026-08-31 星野さん指定／2026-09-02 改訂）

角度（180度・90度・60度…）が主、アスペクト名は従。**名前は添えても、省いてもよい。**
「180度のオポジション」と書いても、「180度で向かい合っています」と書いてもよい。

**ただし、角度を書くのは段落の主役になるアスペクトだけ。**（2026-09-02 追加）
処方に添えるだけの脇役は、角度も名前も出さず「木星とも調和しています」で流す。
1本の鑑定で角度を書くのは**2つまで**。全部に角度を付けると、読み口が資料になる。

```
× オーブ0.25度でほぼ完全に響き合っています   ← 何の角度か分からない
× 協力的な角度で結ばれているので            ← 角度がないので他と揃わない
× 牡牛座の月に、水瓶座の土星がスクエア。     ← 主役に据えるなら角度が要る
○ この月とMCは、60度のセクスタイル。
○ そのアセンダントと牡牛座の太陽は、180度で向かい合っています。
○ さらに火星は、社会での立ち位置をあらわすMCと90度。
○ 土星には「時間をかけて形にする力」があり、木星とも調和しています。  ← 脇役はこれでよい
```

理由：オーブの数値だけを出しても、読み手には**何のアスペクトなのかが伝わらない**。角度さえあれば、
近さは文脈で足りる。オーブは素材選定（3章のスコアリング）に必要な内部データであって、
鑑定文に載せる情報ではない。

- 「協力的な角度」のような、角度も名前もない言い換えにはしない
- 「60度のセクスタイル」のように**角度＋名前**を添えると、占星術を知らない読み手にいちばん通る
- 近さを強調したいときは言葉で表す（「ほぼ完全に重なる」「ぴったりのスクエア」）。数値は使わない
- 根拠ボックス（5-b）も同じ。**アスペクト名のみで、オーブは書かない**

**時刻が不明・概算のときは、ASC・MCが絡むアスペクトそのものを書かない**（2-1の時間非依存素材に寄せる）。
名前を書ける＝その配置を使える、なので、使える／使えないの判断は従来どおり時刻精度で決まる。

## 6. ハウスの言い換え辞書

**本文の表記は「意味＋番号」。**（2026-09-02 変更）
「『日々の仕事や習慣、実務』をあらわす6ハウス」のように、鉤括弧で意味を置いてから番号を書く。
番号があると読み手が自分のチャートと突き合わせられ、意味があると番号だけで終わらない。
番号を伏せて「実際に手を動かして整える部屋」とだけ書く旧表記は使わない。

**意味の語は、この表に登録された候補の中から文脈で選ぶ。** 表にない言い方をその場で作らない。
自由に言い換えると鑑定ごとにハウスの意味がぶれて、別人が書いたものになる。
新しい呼び方が必要になったら、**書き手（星野さん）に確認してこの表に登録してから使う。**

| H | 本文で使う意味の語（「◯◯」をあらわす◯ハウス） | 補足（本文で使う動作・距離の語） |
|---|---|---|
| 1 | 自分自身 | 名乗る・前に出る |
| 2 | 持っているもの、お金 | 手元に残る・稼ぐ |
| 3 | 話す、書く、聞くこと | 話す、書く、聞く |
| 4 | 帰る場所（誰にも見せない素の自分がいる場所）／**家や居場所** | 帰る・素に戻る |
| 5 | 表現して楽しむこと／**好きなこと・自己表現・楽しみ** | 出して遊ぶ |
| 6 | **日々の仕事や習慣、実務**／**体や健康**／**人の役に立つこと** | 半径5mの実務／体・日々の手順／目の前の人のために動く |
| 7 | 一対一で向き合う関係 | 向き合う・組む |
| 8 | 深く分かち合うこと | 深く預ける・受け継ぐ |
| 9 | 遠くへ向かうこと／**学んで一段引き上げること** | 遠くへ行く／知って・学んで一段引き上げる |
| 10 | 社会に立つこと | 外に出す・形にする |
| 11 | 友人や仲間との関わり | 輪の中に入る／**一対一ではなく、友人・仲間・コミュニティ・同じ価値観を持つ人・未来への希望** |
| 12 | ひとりに還る時間／**見えない領域や直感** | 人の目に触れない場所 |

複数登録されているハウスは、その鑑定で扱うテーマで選ぶ。

- 4室 … 素の自分・人に見せない顔が主題なら「帰る場所」／安心して居られる場所が主題なら「家や居場所」。**迷ったら「家や居場所」を優先**（2026-08-27 星野さん指定）
- 5室 … 短く置きたいときは「表現して楽しむこと」／好きなこと・やりたいことそのものが主題なら「好きなこと・自己表現・楽しみ」（2026-09-02 追加）
- 6室 … 実務・仕事の段取りが主題なら「日々の仕事や習慣、実務」／体・無理・疲れが主題なら「体や健康」／奉仕・誰かのために動くことが主題なら「人の役に立つこと」
- 9室 … 距離・未知の場所へ出ていくことが主題なら「遠くへ向かうこと」／学びで自分を引き上げることが主題なら「学んで一段引き上げること」
- 12室 … 孤独・内省が主題なら「ひとりに還る時間」／見えない領域・直感が主題なら「見えない領域や直感」

**意味の語は短く刈り込む。**表の登録語をそのまま貼らず、その鑑定で要る部分だけ取る
（6室で実務の話しかしないなら「日々の仕事や習慣」まで。「、実務」は落とす）。

**すべてのハウスに意味を付けない。**意味を付けるのは、その鑑定の主役になる1〜2ハウスだけ。
脇役は「心をあらわす月は魚座の4ハウス。」のように**番号だけ**で置く。
同じハウスを二度目に出すときも、意味を省いて「牡牛座6ハウスの太陽」と受けてよい（2026-09-02 追加）。

抽象的なハウス名は、本文では右列の**距離や動作の語に落とす**と伝わる。

**選んだ呼び名と、その直後の本文は必ず揃える。** 「グレードアップの部屋」と名付けたのに続く文が
距離の話だと、部屋の名前が本文にかからない。呼び名を選んだ時点で、右列のどの語で書くかも決まる
（2026-08-27 の 1984-08-14 鑑定で発生）。

## 7. 文体ルール（STYLE.mdを継承）

- 断定と余白を混ぜる。核（軸・強み）は言い切る／未来の話は「〜かもしれません」
- 予言・吉凶・脅しは書かない
- 欠点は必ず「〜ゆえです」で反転させてから対処法へ渡す
- スピリチュアル語（波動・エネルギーが〜／宇宙が〜）は使わない
- 「あなたは◯◯な人です」の連発を避ける。一鑑定につき断定の型は2回まで
- 締めは**手渡しの語感**であればよく、型は問わない。「〜な人です。〜してください」の二文は定番のひとつ
  （1966-12-03）。**言い切りで閉じるほうが強い場合はそちらを取る**（1965-05-07＝「この力は一生あなたを
  更新し続けます。」）。締めたあとに補足や戒めの一文を足さない。せっかく上げた着地を引き戻す
- 読み手を指すときは「**あなた**」。「この人」は書き手が外から品定めしているように聞こえるので使わない
  （「〜な人です」の形はそのまま使ってよい。三人称の名詞で名指すのを避ける）
- **呼び名は段落1の冒頭と段落5のまとめだけに置く。** 本文の途中で指すときは「あなた」。
  呼び名を毎段落くり返すと、鑑定文ではなく手紙の口調に寄る（2026-09-02 検討のうえ従来ルールを維持）

### 7-1. 読み手が「自分の話だ」と受け取るための型（2026-09-02 追加）

星野さんのリライトから抽出。以下は毎回使う。

**(1) サインは「一般論 → だからあなたの場合も」の二段で当てる。**
サインの性質をまず一般論として置き、次の文で読み手に接続する。いきなり本人の話にしない。

```
○ 牡牛座は、急いで答えを出すサインではありません。自分の感覚で確かめながら積み重ねていきます。
　 だからあなたの場合も、頭の中だけで考え続けるより、まずやってみること。
× 牡牛座なので、あなたは急がず積み重ねる人です。   ← 決めつけに聞こえる
```

**(2) 内心の声はセリフで改行して並べる。** 説明より、本人の頭の中の言葉をそのまま置くほうが刺さる。

```
「まだ足りない」
「これで出していいのか」
「もっとちゃんとしなければ」
```

2〜3行まで。4行以上は重い。
**直後は「と、自分に厳しくなりやすいかもしれません。」のように地の文で受ける。**
セリフを置きっぱなしにして次の話題へ行かない（2026-09-02 訂正）。

**(3) 行動の提案は対句で書く。** 前半に「やらなくていいこと」、後半に「やること」を置く。**改行するかは任意。**

```
気持ちが整うのを待つのではなく、今日やることをひとつ決める。大きな決意ではなく、毎日の手順に変えていく。
```

改行して並べる形（下）は、対句が主役の段落でだけ使う。多用すると詩に寄る。

```
大きな決意をするより、
今日やることをひとつ決める。
```

**(4) 推量の語尾を厚めに使う。** 「〜でしょう」「〜かもしれません」「〜ことが多いでしょう」「〜こともあるでしょう」。
断定は軸（段落1・段落5）に集中させ、途中の観察は推量で置く。読み手に反論の余地を残すほど、当てはめてもらいやすい。

**(5) 締めは、許可から入るか、言い切りで閉じるかの二択。**
許可型＝「〜しなくても大丈夫です」でゆるめてから、小さい行動をひとつ渡す。
言い切り型＝「考えてから動くのではなく、動きながら答えを確かめていく。／その積み重ねが、◯◯さんにとっての『確かなもの』をつくっていくはずです。」
**毎回どちらかに寄せない。**軸が動作の語で立っているときは言い切り型のほうが強い（2026-09-02 訂正）。

**(6) 弱点は否定形で打ち消さず、「一方で」＋肯定文で資質を言い切る。**（2026-09-02 追加）

```
× 慎重すぎるのではありません。深く関わる力を持っているゆえです。   ← 打ち消しから入ると弱い
○ 一方で、一度動き始めれば簡単には止まりません。集中力や持久力、最後までやり抜く力は、大きな資質です。
```

7章の「〜ゆえです」で反転する型は、弱点の直後に短く挟むとき用。段落を締めるのは肯定文にする。

**(7) 占星術用語は、隠さずその場で定義して使う。**（2026-09-02 追加）
「ステリウム」「逆行」のような用語は、言い換えて消すより、**用語＋一文の定義**で出したほうが読み手の理解が残る。

```
○ この出生図で特に印象的なのが、蠍座のステリウムです。
　 ステリウムとは、ひとつの星座に3つ以上の天体が集まっている配置のこと。
```

定義は一文まで。定義が二文以上要る用語は、そもそも使わない。

**(8) 同じ語尾を1本の中で繰り返さない。** とくに「〜配置です」は**2回まで**。
「〜サインです」「〜ところがあります」「〜でしょう」と散らす。
