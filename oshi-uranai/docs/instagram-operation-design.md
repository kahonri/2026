## 1. アカウントの立ち位置

**「星とカードを読めるようになって、自分で考え、選べる人を増やす」**

星とカードの読み方・使い方を教え、自分で使える人を増やす。現在は星読み中心。二人の役割とプロフィール採用稿はSTATE.md冒頭を参照。

読者に持ってほしい感情の順序：

1. 「なんか、今の自分のことだ」（入口＝日常の言葉）
2. 「へえ、それを星ではそう読むんだ」（納得＝占星術の言葉）
3. 「この人の考え方、なんか好き」（人物への好感）
4. 「自分のことも、この人に読んでもらいたい」（**個人鑑定への接続**）

3が積み上がらないと4は来ない。だから毎回「星の解説」で終わらせず、必ず**私の判断**を出す。

### 一人称・語り口

- 一人称は「私」。敬体（です・ます）ベース。ときどき体言止めと言い切りを混ぜる。
- 予言口調・吉凶断定・専門用語の羅列はしない（従来ルールを踏襲）。
- 「〜と言われています」で逃げない。**「私はこう読みました」と主語を立てる。**
- 断定を避けるための保険表現（「かもしれませんね」の多用）はAI臭のもと。1投稿につき2回まで。

## 2. 投稿カレンダー

### 基本の型：週1本（定例）＋節目（不定期）＝月4〜6本

| 枠 | 頻度 | 内容 |
|---|---|---|
| **定例エッセイ** | 週1（**月曜**） | その週の星の流れを、人間の悩みの言葉から入って書く。主軸。 |
| **節目投稿** | 新月・満月（月2回） | 新月＝始める／整える、満月＝出る／手放す。ワーク性を強める。 |
| **臨時** | 大きい配置のときだけ | 逆行の開始・終了、外惑星のサイン移動など。**なくてよい月があってよい。** |

定例が月曜なのは、「週の頭のモヤモヤ」が読者の生活のリズムと合うため。節目投稿が月曜に重なる週は、**定例と統合して1本にする**（無理に2本にしない）。

### 2-2. 週テーマの選び方（速度フィルタ）

**2026-09-07に追加。** 太陽×火星セクスタイルを週テーマに選んで却下されたことへの対策。

判断軸は**サインの滞在期間ではなく、2天体の離角速度**。太陽（約1.0度/日）と火星（約0.7度/日）はどちらも順行で速度が近いため、差し引き0.36度/日しか離れず、**角度が16日固まる**。これでは「今週」と書けない。

採否は「オーブ3度以内に居座る日数」で決める（≒ 6 ÷ 相対速度）。

| 3度圏の滞在日数 | 扱い |
|---|---|
| 〜3日 | ◎ その週だけの主役。日付が特定できる |
| 4〜8日 | ○ 主役可。ただし**正確日が投稿週の中にある**ことが条件 |
| 9〜15日 | △ 背景に置く。主役にしない |
| 16日〜 | ✕ **週テーマ禁止。** 使うなら「今年の話」として別枠 |

実測例（2026-W37）：

| 配置 | 3度圏 | 判定 |
|---|---|---|
| 海王星-冥王星 セクスタイル | 243日 | ✕ |
| 木星-土星 トライン | 22.5日 | ✕ |
| 太陽-火星 セクスタイル | 16.0日 | ✕ |
| 金星-冥王星 スクエア | 11.0日 | △ |
| 火星-土星 スクエア（8/31に使用） | 9.2日 | △ ぎりぎり |
| 水星-冥王星 トライン | 3.0日 | ◎ |

### 週テーマを探す順番

1. **月相**（新月・上弦・満月・下弦）。7.4日刻みで週とほぼ同期する。**常に第一候補**
2. **サイン移動（ingress）と逆行のステーション**。日付が特定できるイベント
3. **速い天体（月・水星・金星）× 遅い天体のアスペクト**。相対速度が速い方の速度になるので3度圏が2〜4日
4. それ以外

⚠️ `fetch_astro.py` の **【週を通じて持続】タグを「強い根拠」と読まないこと。** あれは「その週ずっとある＝週の輪郭を作れない」という逆の意味にもなる。

### 月の使い分け（テーマにはしない）

月は13〜14度/日で速すぎるため、**週テーマの主役にはしない。**役割を3つに分ける。

| 層 | 使い方 |
|---|---|
| 月相 | 週テーマの第一候補（上記） |
| サイン移動・ボイド | **投稿内の「いつ」**。⑤⑥の受け皿に日付を刺す材料。「木曜の午後は決めない」の粒度 |
| 日々の細部 | ストーリーズ。フィード投稿の主役にしない |

※ボイドを「悪い時間」として煽らない（禁止事項の吉凶断定に触れる）。「決めない・寝かせる時間」として出す。

## 3. 投稿の基本構造：「星 → 私 → あなた → 持ち帰る」

カルーセル **7〜9枚**。1枚目は写真＋コピー。2枚目以降で以下を運ぶ。

| # | ブロック | 役割 | 目安字数 |
|---|---|---|---|
| ⓪ | **掴み** | **人間の言葉のまま、1〜2行だけ。星の話はまだしない** | 20〜50字 |
| ① | **今の星の流れ** | 何が起きているかを1〜2文で | 60〜100字 |
| ② | **日常の言葉に翻訳** | 「つまり、こういうことが起きやすい」 | 100〜150字 |
| ③ | **私に起きたこと** | 実際の出来事。小さくてよい。**具体的な固有名詞を1つ入れる** | 150〜250字 |
| ④ | **私はどう読んだか** | 占い師としての判断。**ここがアカウントの心臓部** | 150〜250字 |
| ⑤ | **あなたの場合は** | 読者に置き換える。問いを1つに絞る | 100〜150字 |
| ⑥ | **持ち帰り（受け皿）** | ワーク・穴埋め・選択肢。**必ず入れる** | 80〜120字 |

### ⓪掴みを必ず入れる（2枚目に星の解説を置かない）

**1枚目が人間の言葉なのに、2枚目でいきなり「火星と土星が90度で」と占星術の言葉に落ちると、めくった瞬間に階層が逆転する。** ここがカルーセルで最もスワイプが切れる位置なので、2枚目も人間の言葉のままにする。

⓪の中身は2種類。**同じ型が3回続かないようにする。**

| 型 | 例 | 使いどころ |
|---|---|---|
| **告白型** | 「毎日投稿にしようとして、やめました。」 | ③に強い出来事がある週 |
| **言い当て型** | 「やる気はあるのに、一歩が出ない。そういう週です。」 | ③が地味な週・節目投稿 |

告白型ばかりだと自分語りのアカウントに見える。**言い当て型を混ぜて、読者の側から始まる回を作る。**

⓪で明かした話は、③で**もう一度明かさない**。③は⓪の続き（具体・細部）から書き始める。

### ③④が抜けると、ただの占い情報アカウントに戻る

- ③を「私を占ってみました」で終わらせない。**自分は実例、結論は読者のもの。**
- ③→④→⑤の接続は必ずこの形：
  「私はこうだった」→「これって、こういう星の使い方ができる」→「じゃあ、あなたの場合は？」

### 3-2. ③の代替：性質・自己観察型（③'）— 2026-09-12 追加

**出来事がない週のための第2の型。** 標準ではなく、逃げ道でもない。

③を「先週こういうことがあった」で書けない週は必ず来る。そこで無理に出来事をひねり出すと、
温度の違う話を1つの段落に同居させて壊れる（2026-09-12にこれで1本潰した）。

そういう週は、③を**出来事ではなく「私はこういうときに、こうなる」**で書く。
設計書3章がもともと③に許している「迷っていること」「やめたいと思っていること」と同じ枠。

**成立させるための条件**

| | |
|---|---|
| **④は必須** | ③'にしても④は省略しない。**④が無いなら投稿を出さない。** ③は④の根拠であって、目的ではない |
| **条件を2つ以上入れる** | 「いつ出るか」「いつ出ないか」「どのくらいの頻度か」から2つ以上。例：「話しているときだけ」「文字なら出ない」「たまに」。**条件が無いと「私はこういう人間です」という自己紹介になり、抽象に落ちる** |
| **一般論を書かない** | 「人は誰でも」「みんなそうですが」は禁止。主語は最後まで私 |
| **⓪は言い当て型にする** | ③'に強い場面が無いぶん、入口は読者の側から始める |
| **2回続けて使わない** | 連続すると、出来事の出てこないアカウントになる |

**なぜ成立するか**：AI臭の原因は「素材ゼロ」であって「出来事ゼロ」ではない（voice.md 0章）。
条件つきの自己観察は、何にでも当てはまる言葉ではないので、素材として機能する。

### ③に書くこと（顔出しはしない）

最近あった小さな出来事／仕事で考えたこと／迷っていること／笑ったこと／やめたいと思っていること／今やろうとしていること。

**私生活の公開が目的ではない。**「この人はこういうことで迷う」「こういう考え方をする」が伝わればよい。

書けるネタがない週は、**その週に撮った写真から逆算する**（何が目に留まったのか＝その週の自分の状態）。

## 4. 受け皿（持ち帰り）のカタログ

⑥は毎回形を変える。同じ型が2回続かないようにする。

| 型 | 例 | 相性のよい星 |
|---|---|---|
| **穴埋め** | 「＿＿＿だから、私は止まっている」の＿を埋める | 土星・スクエア |
| **言い切らせる** | 「本当は、私は＿＿＿したい。」を書いてみる | 火星・満月・牡羊 |
| **1つだけ決める** | 今月やめること1つ／始めること1つ | 新月・乙女 |
| **4択** | 仕事／恋愛／人間関係／自分自身 から選ぶ→選択肢ごとに短いヒントを返す | 情報量の多い週 |
| **YES/NO＋次の問い** | 答えたあとに、次に考える問いを渡す | 天秤・迷いの週 |
| **ミニワーク** | 3分、紙に書き出す。手順を3ステップで示す | 水星・整理の週 |
| **ストーリーズ投票** | 投稿と連動させ、翌日結果を受けて追記を出す | 反応を集めたい週 |

**禁止：**「あなたはどうですか？」で閉じること。読者に判断を丸投げしない。**必ず、読者が自分について1つ言語化できる形で終える。**

## 5. ビジュアル方針

### 5-1. 写真がプロフィールになる

**自分で撮った写真が基本。**（2026-09-29追記：AI生成画像の禁止は解除。リール等でAIイラストも使う）

理由：完成度の高いAI画像が飽和した中で、「実際にこの人が見た景色」だけが代替不能な個性になるため。顔を出さない代わりに、**写真が人物紹介の役をする。**

テーマ：**生活の断片 × 柔らかな光 × 低彩度 × 少し曖昧 × 人の気配**

撮影対象：朝夕の光／窓／カーテン／影／机／ノート／コーヒー／手元／足元／仕事道具／電車の窓／街／雨／水面／植物／夜道／空／移動中に気になったもの。

**「Instagram用の綺麗な写真」を撮ろうとしない。**
少しブレている／ピントが甘い／逆光／構図が変／何を撮ったか一瞬分からない、くらいの偶然性を残す。

判断基準は写真の上手さではなく、**「その週、自分の目に何が引っかかったか」**。

### 5-2. 色・質感（現像の基準値）

| 項目 | 方向 | 目安 |
|---|---|---|
| 彩度 | 低め | −15〜−30 |
| コントラスト | 低め | −10〜−20 |
| 黒レベル | 締めすぎない | 黒を +10 前後で持ち上げる |
| 白レベル | 真っ白にしない | ハイライト −10 前後 |
| 光 | 自然光中心・透明感 | 色温度は少し暖色寄り |
| シャープ | かけすぎない | 標準以下 |
| 粒子 | 必要なら薄く | フィルム質感の範囲で |

キーワード：静かな生活感／光の余韻／途中の瞬間／人の気配／少し曖昧／記憶／日常の断片／quiet／muted／soft light／everyday fragments／documentary／soft focus

**加工しすぎない。** 全投稿で同じプリセットを使い、アカウント全体の色を揃える。

### 5-3. 写真ストックの運用

- 週に**10〜15枚**撮る。使うのは1〜2枚。ストックが常に余っている状態を保つ。
- 保存先：`oshi-uranai/ig-photos/YYYY-MM/`。ファイル名は `YYYYMMDD_短いメモ.jpg`（例：`20260831_夕方の窓.jpg`）。
- 撮った日の状態のメモを1行だけ残す。**③のネタ帳になる。**
- **投稿のために撮りに行かない。** 生活の途中で撮る。撮れなかった週は、ストックから「その週の気分に合うもの」を選ぶ。

## 6. 1枚目のデザイン仕様

**写真が主役。全面写真＋短いコピー。文字量はかなり少なく。**

2026-09-12に**帯**を追加した。根拠は6-2。

```
┌──────────────────────┐
│                      │
│   〔全面写真〕         │
│                      │
│   直さなくていいものを、 │  ← 大きく：人間の言葉（日本語）
│  ▌ 乙女座新月 ▐        │  ← 帯：その回の星の出来事（日本語）
│   直そうとしてた。      │
│                      │
│      NEW MOON IN VIRGO│  ← 小さく：英字。位置を固定する
│      SEP 11          │
└──────────────────────┘
```

### 3つの層

| 層 | 中身 | サイズ | 位置 |
|---|---|---|---|
| **大** | 人間の言葉。24字以内・2〜3行 | 100% | 写真の余白に合わせて毎回変えてよい |
| **帯** | その回の星の出来事を日本語で。8〜12字 | 50〜65% | 大コピーの行間に挟む |
| **英字** | 星のキーワードと日付。2行まで | 25〜33% | **毎回同じ位置に固定する** |

### ルール

- **大きく＝人間の言葉／小さく＝星の言葉。** この階層は毎回崩さない。
- 「乙女座新月」「牡羊座満月」は**捨てない。帯に置く。**
  - 星に詳しくない人 → 大コピーの日常の言葉から入る
  - 星が好きな人 → 帯と英字で「星読みの投稿だ」と分かる
- 大コピーは**24字以内**。1文か、短い2文。句点で切る。
- 文字色は白か、写真から拾った濃いグレー。**縁取り・ドロップシャドウは使わない。** 読めないなら写真側を選び直す。
- **大コピーの配置は毎回同じでなくてよい**（写真の余白に置く）。ただし**帯と英字は位置を固定する。** グリッドで9枚並んだとき、ここが揃っていないと連載に見えない。
- サイズ比と字数の上限は固定。

### 6-2. 帯のルール（2026-09-12 追加）

- 帯に入れるのは**その回の星の出来事の名前だけ**。「乙女座新月」「天王星逆行開始」「火星×土星スクエア」。
- **「星読み」「占星術」「占い」というジャンル名は1枚目に入れない。** 最終枚は10章の2行固定仕様に従う。**表紙で名乗らない。**
- 帯は**1投稿に1本**。イベントが複数ある回でも、主役の1つだけを載せる（禁止事項「1投稿に複数のアスペクトを詰め込む」と同じ理由）。
- **色は使わない。** 白ベタに黒文字か、写真から拾った濃いグレーに白文字。彩度のある帯は5-2の低彩度方針と衝突する。
- 帯は大コピーを上下に分断する位置に置く（人間の言葉で星の言葉を挟む）。挟めない回は大コピーの下に置く。
- 英字は廃止しない。帯と内容が重なるが、**英字は情報ではなく版面を締める要素**として残す。

**根拠（2026-09-12・参考アカウント2件を実見して判断）**

- `mico.serendipity2`（1.1万）：表紙に「星読み」というジャンル名を**出していない**。出ているのは「土星逆行開始」「乙女座新月」という**その回の出来事**と、極小の英字署名（`MICO astrology × subconscious`）だけ。ジャンル名が出るのは最終枚のプロフィール誘導の1回のみ。
- 帯の実例：「未来へ進む前に ／ ▌土星逆行開始▐ ／ もう一度だけ」。**人間の言葉で星の言葉を挟む**ので、コピーは人間の言葉のままでいられる。
- `madoka_journey.words`（9,158）：表紙にも本文にも星の情報がほぼ無く、星の話だと分からない。**空気と署名の置き方だけが参考**で、この問題については参考にならない。
- **輸入するのは mico の「帯」というレイアウト装置ひとつだけ。** 色（金・ティール）・文章・構成は輸入しない。mico の本文語彙（真実／本質／フェーズ／価値／潜在意識を浄化し）は voice.md 2-1・2-2に正面から抵触する。また mico には③（私に起きたこと）が無く、9枚すべてが読者への説明になっている。構成を真似ると③④の居場所が消える。

### タイポグラフィ

- 日本語：明朝系（游明朝／Noto Serif JP など）。字間をやや広く（+50〜100）。行間 1.8 前後。
- 英字：サンセリフの細字（Helvetica Neue Light／Inter Light など）。**字間を大きく開ける（+200〜300）。**
- 写真は生活感と偶然性を残し、**タイポグラフィだけ少しモードにする。** 写真を作り込まず、デザインで整える。

### 2枚目以降

- 白／生成りの無地ベース＋本文。写真は1枚目と、必要なら中盤に1枚まで。
- 本文は1枚あたり**80〜150字**。詰め込まない。
- 最終枚に受け皿（ワーク）。CTAは最終枚の下に小さく。

### デザインテイスト（NGリスト）

宇宙／キラキラ／星空／十二星座のシンボル／女性イラスト を**メインビジュアルにしない**。

目指すのは「小さな個人誌」「カルチャー誌」「写真エッセイ」「静かなエディトリアル」。

## 7. キャプションの型

```
〔1枚目のコピーをそのまま1行〕

〔③私に起きたこと の短縮版・2〜3文〕
〔④私の読み の要約・1〜2文〕

⸻

今週の星：〔配置名と日付・2行まで〕

⸻

〔⑥受け皿を1行で再掲〕
よかったら、コメントかDMで教えてください。

〔ハッシュタグ〕
```

- 冒頭2行で読ませる（「続きを読む」より上に来るのは約2行）。**ここに結論を置かない。引っかかりを置く。**
- 絵文字は使わないか、使っても1投稿に1つまで。
- ハッシュタグは**10〜15個**。キャプション末尾にまとめる。
  - 固定：`#推しの占い子` `#星読み` `#西洋占星術` `#占星術`
  - 可変：その回のテーマ語（`#モヤモヤ` `#自己理解` `#手帳時間` など）＋写真語（`#日常の断片` `#光の記録`）
  - **巨大タグ（#占い #followme 等）は入れない。** 分母を取りにいく段階ではない。

## 8. 人となりの出し方（配分ルール）

半年見た人に「顔は知らないのに、なんとなくこの人を知っている気がする」と思わせるのが目標。
そのために、**毎回すこしずつ、違う面を出す。**

出す面のローテーション（同じ面が3回続かないようにする）：

| 面 | 例 |
|---|---|
| 仕事の考え方 | 判断に迷ったこと、やり方を変えたこと |
| 迷い | まだ決められていないこと |
| やめたこと | 手放した習慣・企画 |
| 笑ったこと | 小さくてどうでもいいこと。**軽い回を混ぜる** |
| 気になったこと | 読んだもの、見かけたもの |
| 星の使い方 | 自分の出生図をどう扱っているか |

**重い回が続かないようにする。** 4本に1本は軽い回を入れる。

## 9. ストーリーズ運用

投稿と別枠で、**週2〜4回**。フィードより気楽に。

- 投稿日：投稿のリマインド＋受け皿の投票（4択・YES/NO）
- 翌日：投票結果を受けた短い追記。**「みんなこう答えました。私はこう読みました」**
- 平常日：撮った写真をそのまま1枚＋1行。ボツ写真の置き場として使う
- 月1回：質問箱を開ける → 集まった質問が**個人鑑定の入口**になる

ハイライトの旧3分類は固定しない。二人の紹介用「はじめに」は追加案。新構成は未確定。
