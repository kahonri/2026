# 推しの占い子｜フォロワー1万人ロードマップ
作成日：2026年9月23日。以下の目標数値は運用仮説であり、達成を保証する予測ではありません。

## 目的と約束
対象：仕事、人間関係、暮らしの選択で「正解を外したくない」と迷う30〜50代。占い好きの人に限らず、内省したい人に届く言葉を使う。
約束：「星とカードを、決めてもらうためではなく、自分の本音を見つけて選ぶために使う」。タグライン「星を読む。カードを読む。そして、自分を読む。」。合言葉「今日、あなたが決める小さな一歩は？」。運勢は断定・恐怖訴求を避け、暦・星の解釈には対象期間と根拠を示す。

- ビューはユニーク人数ではない。単純換算で非フォロワービュー約72、リールビュー約12、リンクタップ／プロフィールアクセス6.25%。後二者は少数で変動が大きい。
- 最近のカルーセル「水星×土星」は9枚。表紙「目玉の飛び出る眼鏡が机にある。」から始まる本人のエッセイで、言葉を伝えることを慎重に考える過程が具体的。世界観は一貫するが、結論と読む便益が後半にあり、初見の発見導線には弱い。文字が細く小さいページがある。白黒の世界観は残しつつ、表紙だけ課題・結果を明記し、1画面1論点、明暗差と文字サイズを上げる。
- プロフィールには「星とカードを、毎日の味方に」「無料・誕生日から1年間の運勢」がある。無料導線が先に見えるので、何が得られ誰が発信するか、鑑定との違いを固定投稿で示す。過去の青・黄・紫の投稿と現在の白黒で見た目が切り替わっているため、今後は白黒＋識別用の1色と固定の表紙体系に統一する。顔出しは不要。手元、生活音、声、文章で本人を見せる。

## 商品と導線
1. 発見：一場面の悩みから始めるリール、保存できる判断ワークのカルーセル。
2. 理解：固定投稿3本「このアカウントの使い方」「星・カードとの付き合い方」「私が決め直した話」。プロフィール案：『推しの占い子｜星とタロットで自分を読む／迷った日に、本音を見つけて自分で選ぶ／週2回の選択ワーク＋中の人の実話／誕生日から1年を読む無料版はこちら↓』。表示文字数と改行を実機で確認。
3. 体験：無料の誕生日から1年の運勢。登録画面に無料範囲、届く時期、必要情報、連絡頻度、解除方法を明記。診断末尾に「今年の自分が選ぶ行動を一つ」を入れる。
4. 深掘り：出生図を使った特徴・弱点・扱い方の個別鑑定、今年と翌年の流れを踏まえた行動指針の鑑定。無料版・有料版の差と価格、納期を明記。既存の無料鑑定を宣伝に使う際は本人の許可を取る。
5. 卒業：「鑑定を受けた後に自分で決めたこと」を任意で振り返る。依存する頻度を増やす訴求はしない。

## 投稿の柱と制作配分
- 最優先「星と暦の節目」：新月・満月は毎回、逆行の開始・終了、外惑星のサイン移動、春分・夏至・秋分・冬至を年間カレンダーに先に確保。逆行やサイン移動がない月に架空の話題を作らない。毎月の投稿枠の3〜5本を予定し、重なる週は通常企画を置換する。
- 通常の投稿は「決める練習」「中の人の選択エッセイ」「無料体験・鑑定紹介」の3系列。節目投稿でも必ず、意味→生活の場面→読者が自分に問うこと→選べる小さな行動を入れる。
- 新月は「これから始めたいこと」、満月は「実ったこと・手放したいこと」、逆行は「見直したいこと」、季節の節目は「3か月の棚卸し」、外惑星のサイン移動は「長期的なテーマを考える入口」。占星術の解釈と天文学上の日時は分けて示し、画一的な吉凶や個人の運命の断定をしない。
- 基本は週3本（リール2、カルーセル1）とストーリーズ週4〜5日。ただし節目が集中した週は週4本、負担が高ければ通常企画を翌週へ。YouTube Shortsへリールを週1〜2本再編集。週あたり制作4〜6時間を想定。
- 制作手順：年初・四半期に節目の日付を日本時間で一覧化→前月に投稿日を確定→7日前に原稿→前日ストーリーズで問い→当日投稿→翌日読者の回答を拾う。新月・満月は事前の「今度の節目」と当日の本編を一組にする。

## 最初の3本の台本
### A：リール15〜25秒「占いに決めてもらわない3つの質問」
画面1「占いを見ても、まだ決められないなら」／画面2「①本当はどっちに傾いてる？」／画面3「②怖いのは失敗？誰かの反応？」／画面4「③今週できる小さな実験は？」／締め「星やカードは、答えではなく問いを増やす道具。あなたの一歩はあなたが選んでいい」。CTA「迷った日に見返せるよう保存」。手元でカードを置く映像＋声、字幕付き。
### B：カルーセル7枚「返事を書く前に、何を決める？」
1「言葉が重くて、返事を送れない日に」／2「私は文面を直す前に、相手の反応を怖がっていた」／3「水星×土星を読むとき、私は『慎重に言葉を選ぶ』という問いを受け取った」／4「選択肢を3つ書いた：今送る／明日送る／短い確認だけ送る」／5「私が選んだのは、一晩置いて短く伝えること」／6「あなたなら何を守りたい？速さ、正確さ、関係性」／7「星は選択を代わらない。自分が選ぶための手がかりに。保存して返事の前に見返してね」。実体験と異なる結末なら5枚目を実際の行動に直す。
### C：リール20秒「タロット二択」
冒頭「左と右、直感で選んで。結果を見る前に理由をひとこと」→2枚のカード→各カードを『予言』ではなく問いに翻訳→「選んだ理由に、いま大切なことが出ているかも」。コメント誘導は「選んだ理由を残してもOK」、個人情報を求めない。
