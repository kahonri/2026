## 目的と優先順位

主目的はInstagramのフォロワー純増。最初に改善するのは「知らない人への到達 → プロフィール訪問 → フォロー」。無料の誕生日メール登録、出生図リーディング、有料鑑定の販売は従指標として記録する。販売開始は大切だが、61人規模の初月に販売件数だけで需要を判定しない。

対象は、仕事・人間関係・暮らしの選択で迷う30〜50代。星とカードを「答えを決めてもらうもの」ではなく、自分で考えて選ぶ道具として教える。本人が撮った写真、実話、占い子ちゃんの整理する役割を保つ。

## 導線

1. **発見**：生活の一場面から始まるリールと節目投稿。初見の人が「自分の話」と分かる言葉を先に置き、星の名前と根拠を続ける。
2. **フォロー**：プロフィールと固定投稿で「見続けると星・カードを自分で読めるようになる」ことを示す。発見用投稿の案内はフォローを中心にする。
3. **無料体験**：誕生日から1年間の運勢は無料。登録の案内は該当する投稿やプロフィールに置く。フォローの代わりになる主指標にはしない。
4. **最初の購入**：パーソナル出生図リーディング（試行価格2,000円）。生年月日・出生地・分かれば出生時刻だけを受け取り、出生図から読める本人の傾向・持ち味・心が満たされる条件・つまずきやすさと活かし方を約1,000字で届ける。相談内容は聞かず、現在の星の動き・時期の予測・質問往復は含めない。詳細は `product-tiers.md` と `natal-reading-design.md`。
5. **深い個別鑑定**：5,000円のパーソナル星読み鑑定は、相談内容と現在の星の動きを含む。対面付き8,000円は別の提供形態。既存の2年前の無料申込者には遡って請求しない。

各投稿の案内は目的に合わせて一つに絞る。固定の「週2販売・週3保存・週2交流」というローテーションは使わない。

## 記録と判定

毎週、投稿後7日で次を記録する。ビューは延べ表示、到達アカウントは人数なので混同しない。表示されない指標は空欄とし、推計で埋めない。

| 段階 | 記録する数 |
|---|---|
| 発見 | 投稿別の非フォロワー到達、リールの視聴維持・平均視聴（取得できる場合） |
| 興味 | 投稿別のプロフィールアクセス、保存、シェア |
| フォロー | 投稿別フォロー（取得できる場合）、週のフォロワー純増 |
| 体験・販売 | 無料登録、2,000円商品の案内閲覧・申込・総制作分数、5,000円鑑定の問い合わせ・購入 |

母数が小さい間は率と絶対数を併記し、1本の成功・失敗を一般化しない。4週間後は、非フォロワー到達とフォローの両方を生んだ題材を一つ選び、同じ悩みを別の実例で再試行する。到達はあるがフォローが弱ければプロフィールと固定投稿、到達自体が弱ければ冒頭と題材を見直す。保存だけが高ければ既存読者向けの価値として残し、発見の勝ち筋とは分けて判断する。

10/23のフォロワー100〜150人と月間非フォロワー到達500人は、それぞれ挑戦目標・発見実験の目安。61人から39〜89人増やすには、到達500人だけを母数とすれば7.8〜17.8%のフォローが必要となるため、二つを達成予測として結び付けない。12/23以降の数値も実績に応じて更新する。

## 出生図リーディングの試行判定

上限5件は受注負荷を抑える枠で、販売達成目標ではない。試行価格は2,000円。1件の受付・作成・送付を含む総作業時間を測る。30分を超える状態が続けば、必要な品質を削る前に価格と受付数を見直す。0件でも、案内を見た人数が少なければ需要や価格への結論を出さない。感想の公開は本人の許可を得てから行う。
