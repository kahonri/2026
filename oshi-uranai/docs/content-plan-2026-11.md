## 3. 柱は4つ

### ① 水曜21:00「3枚から1枚」タロットリール【主エンジン・新設】

フォロワー数を伸ばす中心。**選ぶこと自体が「私はどうしたい？」の練習**になり、コンセプトと形式が噛み合う。

- **カードはユーザーが実際に3枚引く**（引いていないカードは書かない、のルールのまま）。前の案の12枚より軽い
- 構成（20〜25秒）：
  1. 冒頭2秒：悩みの一言＋「直感で1枚選んで」（例：「『いいよ』って言ったあと、モヤっとした人へ。直感で1枚。」）
  2. 伏せた3枚に番号（1・2・3）→「止めて選んで」で2〜3秒
  3. 1→2→3の順にめくる。各カードに、言い切りの読み＋今週の一歩を1つずつ
  4. 締め：「何番でしたか？コメントで教えて」→ エンドカード
- **題材はいつも理想像の悩みから。** 恋愛運・金運のような占いのテーマから入らない
- 見る数字：コメント数（番号を答える）・3秒離脱率・非フォロワーの割合・プロフィールへのアクセス
- 作り方：`make_reel.py` のタロット系統（10/5の型）を土台に、伏せ札3枚と「止めて選んで」の場面を足す（新しいテンプレートが必要）

### ② 月曜7:30「今週の星読み」【習慣・既存】

形は今のまま。1つだけ足す：
- **最後から2枚目に、選んで答えるページを置く**（例：「今週のあなたはどっち？ A 先に言う／B 一晩おく」→ コメントで答える）。自由回答の「あなたはどう？」より答えやすい

### ③ 月2回「私の出生図で読む私」【信頼・新設】

moco型。原点の話（「人にどう思われる？」から「私はどうしたい？」へ）を、あなた自身の出生図で見せる。

- 例：「私の月は〇〇座。人に合わせすぎていた理由が、ここにありました」→ 図の実物 → 私がどう読んだか → **あなたの月も表で探して**（読者が自分でやるページ）
- **自分解説書（2,000円）の案内を自然に置ける回。** 「自分の図を自分で読むのが難しければ、私が読みます」。今のルール（キャプションでの案内は節目の回だけ）に、この回を足す
- **方法に名前をつける**：毎回同じ手順で読む（例：「星で輪郭、カードで今、言葉で答え」）。講座の看板の候補になる。名前はユーザーが決める
- 他人が出てくる話の扱い（下の5章）

### ④ 節目の2日前〜前日【発見・既存】

ルールは今のまま。題材の入り方だけ①と同じにする（星の名前からではなく、理想像の悩みから入る）。

**本数**：毎週2本（月・水）＋節目＋月2回の③。今より、毎週の水曜リール1本と月2回の③が増える。

## 4. 言い切りの考え方（前の版から修正）

| | 中身 |
|---|---|
| 言い切る | 星・カードの意味と読み方（「金星は『好き』の星」「このカードは、もう決めている人に出る」）／今週の一歩 |
| 読者に選んでもらう | その人の答え（「1・2・3のどれ？」「AとBのどっち？」） |
| 言い切らない | 未来の出来事・吉凶・他人の気持ち |

前の版の「締めは答えを1つ言い切る」は、占いの結果を渡す形に近く、講座の目的（自分で読めるようになる）とずれる。弱かったのは「言い切らないこと」ではなく、**問いが自由回答で答えにくかったこと**と考える。3枚から1枚の形は、この両方（意味は言い切る・答えは読者が選ぶ）を自然に満たす。

## 5. 自分の話を出すときの線引き（案）

ユーザーが「ほかの人に迷惑がかかることは言いたくない」と言っていることを、原稿づくりの確認項目にする。

- 他人が出てくる話は、**関係と場面まで**にする（「前の職場で」「家族に言われて」）。名前・職場名・特定できる出来事は書かない
- **その人が読んでも嫌な気持ちにならない書き方**にする。相手を悪く書いて自分を正当化する形にしない
- **鑑定のお客さんの話は使わない。** 感想は掲載の許可を取ったものだけ（今のルールのまま）
- Claudeは、ユーザーが話していない他人の行動や台詞を推測で足さない
- 迷ったら出さない。最終判断はユーザー
